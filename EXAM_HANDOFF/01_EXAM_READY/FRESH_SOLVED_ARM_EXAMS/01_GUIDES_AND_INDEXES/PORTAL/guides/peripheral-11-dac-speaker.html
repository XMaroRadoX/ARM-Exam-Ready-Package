11. DAC / speaker

Validated 10-bit samples and timer-driven table playback.

Jump to code ↓
On this pageCanonical contract
DACSpeakerTimer IRQPeriodic

The DAC accepts samples from 0 through 1023.

Show C code
C
exam_dac_init();
(void)exam_dac_write(512);

For a waveform, configure one timer, acknowledge MR0 in its handler, advance a bounded table index, and call exam_dac_write() once. The API deliberately does not hide the timer inside a playback service.
