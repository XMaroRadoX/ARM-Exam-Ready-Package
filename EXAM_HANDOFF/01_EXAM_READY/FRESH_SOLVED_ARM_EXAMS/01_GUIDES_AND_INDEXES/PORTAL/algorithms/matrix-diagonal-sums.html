Main and secondary diagonal sums

Square row-major matrix with n<=256. Write main and secondary sums into two 64-bit outputs. Empty matrix yields two zeros. Require capacity>=2 and valid output; nonempty input must be valid and disjoint.

Problem and contract

Square row-major matrix with n<=256. Write main and secondary sums into two 64-bit outputs. Empty matrix yields two zeros. Require capacity>=2 and valid output; nonempty input must be valid and disjoint.

C interface

CODE
int diagonal_sums(const int16_t *a, uint32_t n, int64_t *out, uint32_t capacity)

Register map

FunctionArgumentEntry location
diagonal_sumsconst int16_t *aR0
diagonal_sumsuint32_t nR1
diagonal_sumsint64_t *outR2
diagonal_sumsuint32_t capacityR3

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Load a[i*n+i] for the main diagonal.
  2. Load a[i*n+n-1-i] for the secondary diagonal.
  3. Store both widened sums; each diagonal includes its own center.

Worked trace

[[1,2,3],[4,5,6],[7,8,9]] -> [15,15].

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
int diagonal_sums(const int16_t *a, uint32_t n, int64_t *out, uint32_t cap) {
  if (!out || cap < 2 || n > 256 || (!a && n))
    return 0;
  int32_t x = 0, y = 0;
  for (uint32_t i = 0; i < n; i++) {
    x += a[i * n + i];
    y += a[i * n + n - 1 - i];
  }
  out[0] = x;
  out[1] = y;
  return 1;
}

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
