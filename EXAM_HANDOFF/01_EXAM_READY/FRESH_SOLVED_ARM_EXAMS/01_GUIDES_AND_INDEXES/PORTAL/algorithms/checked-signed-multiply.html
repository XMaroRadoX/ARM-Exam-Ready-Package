Problem and contract

Exam question

Write a C function and matching ARMASM subroutine named checked_multiply_i32 to multiply signed integers with overflow detection. Use the exact interface below, obey the stated failure behaviour, and preserve the AAPCS register and stack rules.

Return 1 and the exact signed 32-bit result. Return 0 without writing when result_out is null or the mathematical result is outside INT32_MIN..INT32_MAX.

C interface

CODE
int checked_multiply_i32(int32_t left, int32_t right, int32_t *result_out)

Register map

FunctionArgumentEntry location
checked_multiply_i32int32_t leftR0
checked_multiply_i32int32_t rightR1
checked_multiply_i32int32_t *result_outR2

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Compute a widened result or inspect the ARM overflow condition.
  2. Reject overflow before storing.
  3. Publish the result only on success.

Worked trace

The safe example produces -42; the boundary example INT32_MAX,2 is rejected.

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
/* Exam prompt: Multiply signed integers with overflow detection
 * Contract: Return 1 and the exact signed 32-bit result. Return 0 without writing when
 * result_out is null or the mathematical result is outside INT32_MIN..INT32_MAX.
 * Method:
 * 1. Compute a widened result or inspect the ARM overflow condition.
 * 2. Reject overflow before storing.
 * 3. Publish the result only on success.
 */
int checked_multiply_i32(int32_t left, int32_t right, int32_t *result_out) {
  if (!result_out)
    return 0;
  int64_t wide = (int64_t)left * right;
  if (wide < INT32_MIN || wide > INT32_MAX)
    return 0;
  *result_out = (int32_t)wide;
  return 1;
}

#define CHECK(x) do { if (!(x)) return __LINE__; } while (0)
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
int checked_multiply_i32(int32_t left, int32_t right, int32_t *result_out);
int test_main(void) {
  int32_t out = 77;
  CHECK(checked_multiply_i32(-6, 7, &out) && out == -42);
  out = 77;
  CHECK(!checked_multiply_i32(INT32_MAX, 2, &out) && out == 77);
  CHECK(!checked_multiply_i32(1, 2, 0));
  return 0;
}

Common exam mistakes

  • Performing signed overflow first and trying to detect it afterward.
  • Forgetting that signed division truncates toward zero.
  • Writing an output before division-by-zero, range or overflow checks are complete.

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
