7. SysTick

The 24-bit CPU timer and safe millisecond/tick configuration.

Jump to code ↓
On this pageCanonical contract
SysTickSysTick IRQPeriodic

exam_systick_config_ms() and exam_systick_config_ticks() configure and start SysTick immediately. The hardware acknowledges SysTick automatically.

Show C code
C
exam_systick_config_ms(10u);

void SysTick_Handler(void)
{
  exam_events_set(1u);
}

The tick count must fit the 24-bit LOAD register after subtracting one. Stop it with exam_systick_stop() when the question is complete.
