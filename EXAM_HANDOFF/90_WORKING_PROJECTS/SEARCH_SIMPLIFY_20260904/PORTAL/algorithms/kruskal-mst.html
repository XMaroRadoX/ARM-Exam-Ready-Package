Problem and contract

Supply edges sorted by nondecreasing weight, n=1..256, valid endpoints and n parent words. Return MST weight or UINT_MAX for invalid ordering/endpoints, disconnection or total overflow. This generic MST differs from the supplied maze-generation exam.

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Validate ordering and endpoints.
  2. Initialize one component per vertex.
  3. Accept edges joining different roots, checking total weight.

Worked trace

Sorted edges (0,1,2),(1,2,3),(0,2,9): accept the first two, total 5.

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
typedef struct {
  size_t u, v;
  unsigned w;
} MstEdge;
static size_t mst_root(size_t *p, size_t x) {
  while (p[x] != x) {
    p[x] = p[p[x]];
    x = p[x];
  }
  return x;
}
unsigned kruskal_mst(const MstEdge *e, size_t m, size_t n, size_t *p) {
  if (!p || !n || n > 256 || (!e && m) || m > UINT32_MAX / 12)
    return UINT_MAX;
  for (size_t i = 0; i < m; i++)
    if (e[i].u >= n || e[i].v >= n || (i && e[i].w < e[i - 1].w))
      return UINT_MAX;
  for (size_t i = 0; i < n; i++)
    p[i] = i;
  size_t used = 0;
  unsigned total = 0;
  for (size_t i = 0; i < m && used + 1 < n; i++) {
    size_t a = mst_root(p, e[i].u), b = mst_root(p, e[i].v);
    if (a != b) {
      if (e[i].w >= UINT_MAX - total)
        return UINT_MAX;
      p[b] = a;
      total += e[i].w;
      used++;
    }
  }
  return used + 1 == n ? total : UINT_MAX;
}

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
