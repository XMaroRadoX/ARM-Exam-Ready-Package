JoystickJoystick

Exact declaration

C
uint32_t exam_joystick_read(void);

Contract

Preconditions

Call exam_joystick_init() first.

Parameters

This function has no parameters.

Return value

Bits EXAM_JOY_SELECT, DOWN, LEFT, RIGHT, and UP; a set bit means currently pressed. The API supports all 8 directions as combinations of four direction bits, plus a separate centre SELECT press. Diagonals are UP | LEFT, UP | RIGHT, DOWN | LEFT, and DOWN | RIGHT (use the EXAM_JOY_ prefix for each flag). There are no separate diagonal constants and no four-direction restriction in the API. Both inputs must be activated by the board or simulator. Follow the exam question: implement four directions when it asks for four, and diagonals when required.

Side effects

None.

Timing and call context

Single bounded GPIO read; it returns levels, not debounced events.

Scenario usage

Poll joystick press edges every 10 ms

Observed in the reviewed 2025 rhythm and 2026 Bulls-and-Cows/Mastermind solutions. Reviewed exam: 2025-07-01-arm1-q3, 2026-06-25-arm1-q2

C
static uint32_t previous_joystick;
#define EVENT_JOYSTICK (1u << 0)

void RIT_IRQHandler(void) {
  uint32_t current, pressed;
  exam_rit_ack();
  current = exam_joystick_read();
  pressed = exam_joystick_pressed_edges(previous_joystick, current);
  previous_joystick = current;
  if (pressed != 0u) exam_events_set(EVENT_JOYSTICK);
}

exam_joystick_init();
previous_joystick = exam_joystick_read();
if (exam_rit_config_ms(10u) == EXAM_OK) exam_rit_start();

Minimal example

C
uint32_t current = exam_joystick_read();
uint32_t diagonal = EXAM_JOY_UP | EXAM_JOY_RIGHT;
if ((current & diagonal) == diagonal) {
    /* UP and RIGHT are both held. */
}

Common mistake

Inverting the returned mask again even though the helper already converts active-low input to pressed=1.

Exam use

Test the current held-state mask for a diagonal; the two controls may become pressed in different samples, so requiring both pressed-edge bits together can miss it. A held-state test remains true while held; implement one-action or repeat behavior separately as required by the paper.
