LSD radix sort

Stable unsigned sort using four byte passes. a and tmp each hold n words and must not overlap; exact alias is rejected. Empty input succeeds. Uses 256 word counters on the stack.

Problem and contract

Stable unsigned sort using four byte passes. a and tmp each hold n words and must not overlap; exact alias is rejected. Empty input succeeds. Uses 256 word counters on the stack.

C interface

CODE
int radix_sort_u32(uint32_t *a, size_t n, uint32_t *tmp)

Register map

FunctionArgumentEntry location
radix_sort_u32uint32_t *aR0
radix_sort_u32size_t nR1
radix_sort_u32uint32_t *tmpR2

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Count byte frequencies.
  2. Turn counts into starting offsets.
  3. Scatter stably into scratch and copy back, for shifts 0,8,16,24.

Worked trace

[256,1,0xFFFFFFFF,0] -> [0,1,256,0xFFFFFFFF].

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
int radix_sort_u32(uint32_t *a, size_t n, uint32_t *tmp) {
  if (!n)
    return 1;
  if (!a || !tmp || a == tmp)
    return 0;
  size_t count[256];
  for (unsigned shift = 0; shift < 32; shift += 8) {
    for (size_t b = 0; b < 256; b++)
      count[b] = 0;
    for (size_t i = 0; i < n; i++)
      count[(a[i] >> shift) & 255]++;
    size_t sum = 0;
    for (size_t b = 0; b < 256; b++) {
      size_t c = count[b];
      count[b] = sum;
      sum += c;
    }
    for (size_t i = 0; i < n; i++) {
      unsigned b = (a[i] >> shift) & 255;
      tmp[count[b]++] = a[i];
    }
    for (size_t i = 0; i < n; i++)
      a[i] = tmp[i];
  }
  return 1;
}

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
