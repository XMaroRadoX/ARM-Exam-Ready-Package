How to recognize it

At most four ordinary word arguments.

When not to use it

Not a universal rule for doublewords or structs.

Inputs and outputs

Keep symbol, types, and argument order synchronized.

Solving method

TEXT
1. Write exact C prototype
2. map words R0-R3
3. preserve needed inputs
4. return required value

Worked trace

f(a,b,c,d) starts a=R0,b=R1,c=R2,d=R3.

C approach

Make the contract explicit in types and parameters. Keep symbol, types, and argument order synchronized.

Assembly considerations

Map this contract to registers, memory widths, and the frame before translating the steps. Not a universal rule for doublewords or structs.

Adaptation checklist

Keep symbol, types, and argument order synchronized.

Boundary tests

distinct argument values; zero; caller preserved registers.

Common mistakes

Not a universal rule for doublewords or structs. Use the trace above to locate the first differing step.

; Recommended exam template: nested search with a controlled inner-loop break.
; C prototype: int first_equal_pair(const uint32_t *a, const uint32_t *b,
;                                  uint32_t n, uint32_t m);
; Returns (i << 16) | j for the first equal pair, or -1.

                AREA    |.text|, CODE, READONLY
                PRESERVE8
                THUMB
                EXPORT  first_equal_pair

first_equal_pair PROC
                PUSH    {R4-R6, LR}
                MOVS    R4, #0
outer_loop      CMP     R4, R2
                BHS     pair_not_found
                LDR     R5, [R0, R4, LSL #2]
                MOVS    R6, #0
inner_loop      CMP     R6, R3
                BHS     outer_next
                LDR     R12, [R1, R6, LSL #2]
                CMP     R5, R12
                BEQ     pair_found
                ADDS    R6, R6, #1
                B       inner_loop
outer_next      ADDS    R4, R4, #1
                B       outer_loop
pair_found      LSLS    R0, R4, #16
                ORRS    R0, R0, R6
                POP     {R4-R6, PC}
pair_not_found  MOVS    R0, #0
                MVNS    R0, R0
                POP     {R4-R6, PC}
                ENDP

                END

#include <stdint.h>
int first_equal_pair(const uint32_t*a,const uint32_t*b,uint32_t n,uint32_t m){uint32_t i,j;for(i=0;i<n;i++)for(j=0;j<m;j++)if(a[i]==b[j])return (int)((i<<16)|j);return -1;}
