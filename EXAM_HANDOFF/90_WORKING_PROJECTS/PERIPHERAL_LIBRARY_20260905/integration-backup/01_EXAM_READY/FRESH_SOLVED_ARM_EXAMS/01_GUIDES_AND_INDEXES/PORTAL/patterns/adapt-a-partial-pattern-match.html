How to recognize it

Reuse a technique when the new contract differs.

When not to use it

Similar titles are not proof of interchangeable code.

Inputs and outputs

Keep shared invariants and never copy old magic constants without evidence.

Solving method

TEXT
1. Compare the unsigned-byte and signed-byte matrix projects
2. retain row-major offset arithmetic
3. change prototype and LDRB to LDRSB together
4. rerun the same high-bit byte case

Worked trace

At row1,column0 of a2x3 matrix, byte0x80 returns128 unsigned and-128 signed; address and stride remain identical.

C approach

Make the contract explicit in types and parameters. Keep shared invariants and never copy old magic constants without evidence.

Assembly considerations

Map this contract to registers, memory widths, and the frame before translating the steps. Similar titles are not proof of interchangeable code.

;                                   uint32_t column);

                AREA    |.text|, CODE, READONLY
                PRESERVE8
                THUMB
                EXPORT  matrix_get_u8

                MUL     R1, R1, R2
                ADDS    R1, R1, R3
                LDRB    R0, [R0, R1]
                BX      LR
                ENDP

                END
