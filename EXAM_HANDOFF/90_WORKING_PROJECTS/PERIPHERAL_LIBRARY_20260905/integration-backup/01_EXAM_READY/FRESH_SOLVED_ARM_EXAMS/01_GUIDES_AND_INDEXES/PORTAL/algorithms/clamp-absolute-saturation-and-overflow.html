Clamp absolute saturation and overflow

Clamp signed 64-bit values into chosen signed-word limits. Reversed limits return minimum. Absolute INT32_MIN is returned as unsigned 2147483648; signed addition saturates.

Problem and contract

Clamp signed 64-bit values into chosen signed-word limits. Reversed limits return minimum. Absolute INT32_MIN is returned as unsigned 2147483648; signed addition saturates.

C interface

CODE
int32_t algorithm_clamp_absolute_saturation_and_overflow(int64_t value, int32_t minimum, int32_t maximum);
uint32_t algorithm_clamp_absolute_saturation_and_overflow_abs_i32(int32_t value);
int32_t algorithm_clamp_absolute_saturation_and_overflow_add_i32(int32_t first, int32_t second);

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Compare widened value to bounds.
  2. Clamp outside values.
  3. Compute absolute through int64.
  4. Use widened addition before saturation.

Worked trace

INT32_MAX+1 saturates to INT32_MAX.

Matching C

C
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

/*
 * Exam-study reference: Clamp absolute saturation and overflow.
 * Recognition cue: clamp signed arithmetic without overflow.
 *
 * Contract rules:
 * - Fixed-width types make width and signedness part of the interface.
 * - A pointer never carries its length; count/capacity arguments are explicit.
 * - const input objects are not mutated. Non-const outputs may be changed only
 *   within their documented bounds.
 * - Invalid, empty, duplicate and arithmetic-limit behavior is executable in
 *   pattern_edge_vectors() and described in the adjacent README.
 *
 * Trace the validation step first, then the main loop/recurrence invariant,
 * then the final result or capacity check. Public suffix functions are named
 * variants of the same advertised pattern, not unrelated shortcuts.
 */

/* Primary algorithm and its named variants. */

int32_t algorithm_clamp_absolute_saturation_and_overflow(int64_t value, int32_t minimum,
                                                         int32_t maximum) {
  if (minimum > maximum) {
    return minimum;
  }
  if (value < minimum) {
    return minimum;
  }
  if (value > maximum) {
    return maximum;
  }
  return (int32_t)value;
}

uint32_t algorithm_clamp_absolute_saturation_and_overflow_abs_i32(int32_t value) {
  return (value < 0) ? (uint32_t)(-(int64_t)value) : (uint32_t)value;
}

int32_t algorithm_clamp_absolute_saturation_and_overflow_add_i32(int32_t first,
                                                                 int32_t second) {
  return algorithm_clamp_absolute_saturation_and_overflow((int64_t)first + second,
                                                          INT32_MIN, INT32_MAX);
}

static int pattern_core_vector(void) {
  return algorithm_clamp_absolute_saturation_and_overflow(50, 0, 10) == 10 &&
         algorithm_clamp_absolute_saturation_and_overflow(-2, 0, 10) == 0;
}
static int pattern_edge_vectors(void) {
  return algorithm_clamp_absolute_saturation_and_overflow(5, 10, 0) == 10 &&
         algorithm_clamp_absolute_saturation_and_overflow_abs_i32(INT32_MIN) ==
             UINT32_C(2147483648) &&
         algorithm_clamp_absolute_saturation_and_overflow_add_i32(INT32_MAX, 1) ==
             INT32_MAX &&
         algorithm_clamp_absolute_saturation_and_overflow_add_i32(INT32_MIN, -1) ==
             INT32_MIN;
}
int pattern_test_suite(void) {
  if (!pattern_core_vector())
    return __LINE__;
  if (!pattern_edge_vectors())
    return __LINE__;
  return 0;
}
int test_main(void) { return pattern_test_suite(); }

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
