Bounded zero-one knapsack

How to recognize it

Choose each item at most once within capacity.

When not to use it

Ascending one-dimensional updates reuse an item.

Inputs and outputs

State zero-weight policy and whether reconstruction is required.

Solving method

TEXT
1. Initialize DP
2. for each item iterate capacity downward
3. compare take/not-take

Worked trace

item weight2,value3,capacity4 ->value3 not6.

C approach

Make the contract explicit in types and parameters. State zero-weight policy and whether reconstruction is required.

Assembly considerations

Map this contract to registers, memory widths, and the frame before translating the steps. Ascending one-dimensional updates reuse an item.

Adaptation checklist

State zero-weight policy and whether reconstruction is required.

Boundary tests

zero items; overweight item; exact fit; capacity0.

Common mistakes

Ascending one-dimensional updates reuse an item. Use the trace above to locate the first differing step.

C
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

/*
 * Exam-study reference: Bounded zero-one knapsack.
 * Recognition cue: maximum value within capacity.
 *
 * Contract rules:
 * - Fixed-width types make width and signedness part of the interface.
 * - A pointer never carries its length; count/capacity arguments are explicit.
 * - const input objects are not mutated. Non-const outputs may be changed only
 *   within their documented bounds.
 * - Invalid, empty, duplicate and arithmetic-limit behavior is executable in
 *   pattern_edge_vectors() and described in the adjacent README.
 *
 * Trace the validation step first, then the main loop/recurrence invariant,
 * then the final result or capacity check. Public suffix functions are named
 * variants of the same advertised pattern, not unrelated shortcuts.
 */

/* Primary algorithm and its named variants. */
uint32_t algorithm_algorithm_pat_alg_knapsack_001_c(const uint16_t *wt, const uint16_t *val,
                              uint32_t n, uint32_t cap, uint32_t *dp) {
  uint32_t i, c;
  if (!dp || ((!wt || !val) && n) || cap >= UINT32_MAX / 4u || n > 65535u) return 0;
  for (c = 0; c <= cap; c++)
    dp[c] = 0;
  for (i = 0; i < n; i++)
    for (c = cap + 1; c > wt[i];) {
      uint32_t x = --c, v = dp[x - wt[i]] + val[i];
      if (v > dp[x])
        dp[x] = v;
    }
  return dp[cap];
}
