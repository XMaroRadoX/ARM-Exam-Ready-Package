How to recognize it

A function executes BL or BLX.

When not to use it

Saving LR after the nested call is too late.

Inputs and outputs

Account for locals and extra arguments in the same frame diagram.

Solving method

TEXT
1. Save original LR and changed callee registers
2. maintain alignment
3. preserve live scratch
4. restore one exit

Worked trace

SP=S -> PUSH R4,LR -> S-8 -> BL -> POP -> S.

C approach

Make the contract explicit in types and parameters. Account for locals and extra arguments in the same frame diagram.

Assembly considerations

Map this contract to registers, memory widths, and the frame before translating the steps. Saving LR after the nested call is too late.

Adaptation checklist

Account for locals and extra arguments in the same frame diagram.

Boundary tests

multiple calls; early failure; caller sentinels.

Common mistakes

Saving LR after the nested call is too late. Use the trace above to locate the first differing step.

Source/ASM_funct.s
Open raw Assembly file
ASSEMBLY
; Recommended exam template: function that calls another function
; C prototype: uint32_t add_square(uint32_t a, uint32_t b);
; R4 is callee-saved. BL overwrites LR, so both are saved.
; PUSH/POP cover two registers (8 bytes), preserving public-call alignment.

                AREA    |.text|, CODE, READONLY
                PRESERVE8
                THUMB
                EXPORT  add_square

add_square      PROC
                PUSH    {R4, LR}
                MOV     R4, R1
                BL      square_value
                ADDS    R0, R0, R4
                POP     {R4, PC}
                ENDP

square_value    PROC
                MUL     R0, R0, R0
                BX      LR
                ENDP

                END
