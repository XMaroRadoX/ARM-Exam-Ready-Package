Consume-once duplicate-safe matching

Each item may match at most once

How to recognize it

Each item may match at most once.

When not to use it

Counting every equal pair overcounts duplicates.

Inputs and outputs

Preserve separate used flags or equivalent multiplicity limits.

Solving method

TEXT
1. Mark exact/consumed items
2. search only unused candidates
3. consume once
4. count

Worked trace

[1,1] versus[1,2] permits one match, not two.

C approach

Make the contract explicit in types and parameters. Preserve separate used flags or equivalent multiplicity limits.

Assembly considerations

Map this contract to registers, memory widths, and the frame before translating the steps. Counting every equal pair overcounts duplicates.

Adaptation checklist

Preserve separate used flags or equivalent multiplicity limits.

Boundary tests

all duplicates; exact plus misplaced; exhausted candidates.

Common mistakes

Counting every equal pair overcounts duplicates. Use the trace above to locate the first differing step.

/*
 * Exam-study reference: Consume-once duplicate-safe matching.
 * Recognition cue: Bulls and Cows Mastermind duplicate-safe match.
 *
 * Contract rules:
 * - Fixed-width types make width and signedness part of the interface.
 * - A pointer never carries its length; count/capacity arguments are explicit.
 * - const input objects are not mutated. Non-const outputs may be changed only
 *   within their documented bounds.
 * - Invalid, empty, duplicate and arithmetic-limit behavior is executable in
 *   pattern_edge_vectors() and described in the adjacent README.
 *
 * Trace the validation step first, then the main loop/recurrence invariant,
 * then the final result or capacity check. Public suffix functions are named
 * variants of the same advertised pattern, not unrelated shortcuts.
 */

/* Primary algorithm and its named variants. */
uint32_t algorithm_algorithm_pat_alg_consume_once_match_001_assembly(const uint8_t *secret,
                                        const uint8_t *guess, uint32_t n,
                                        uint32_t *cows);



static int pattern_core_vector(void) {
  uint8_t s[] = {1, 1, 2, 3}, g[] = {1, 2, 1, 4};
  uint32_t c = 0;
  return algorithm_algorithm_pat_alg_consume_once_match_001_assembly(s, g, 4, &c) == 1 && c == 2;
}
static int pattern_edge_vectors(void) {
  uint8_t a[] = {1}, b[] = {2};
  uint32_t c = 9;
  return algorithm_algorithm_pat_alg_consume_once_match_001_assembly(a, b, 0, &c) == 0 && c == 0 &&
         algorithm_algorithm_pat_alg_consume_once_match_001_assembly(a, b, 1, &c) == 0 && c == 0 &&
         algorithm_algorithm_pat_alg_consume_once_match_001_assembly(a, b, 33, &c) == 0;
}
int pattern_test_suite(void) {
  if (!pattern_core_vector())
    return __LINE__;
  if (!pattern_edge_vectors())
    return __LINE__;
  return 0;
}
int test_main(void) { return pattern_test_suite(); }

Source/reference.c
Open raw C file
C
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

/*
 * Exam-study reference: Consume-once duplicate-safe matching.
 * Recognition cue: Bulls and Cows Mastermind duplicate-safe match.
 *
 * Contract rules:
 * - Fixed-width types make width and signedness part of the interface.
 * - A pointer never carries its length; count/capacity arguments are explicit.
 * - const input objects are not mutated. Non-const outputs may be changed only
 *   within their documented bounds.
 * - Invalid, empty, duplicate and arithmetic-limit behavior is executable in
 *   pattern_edge_vectors() and described in the adjacent README.
 *
 * Trace the validation step first, then the main loop/recurrence invariant,
 * then the final result or capacity check. Public suffix functions are named
 * variants of the same advertised pattern, not unrelated shortcuts.
 */

/* Primary algorithm and its named variants. */
uint32_t algorithm_algorithm_pat_alg_consume_once_match_001_c(const uint8_t *secret,
                                        const uint8_t *guess, uint32_t n,
                                        uint32_t *cows) {
  uint8_t used_s[32] = {0}, used_g[32] = {0};
  uint32_t i, j, b = 0, c = 0;
  if (!secret || !guess || !cows || n > 32)
    return 0;
  for (i = 0; i < n; i++)
    if (secret[i] == guess[i]) {
      used_s[i] = used_g[i] = 1;
      b++;
    }
  for (i = 0; i < n; i++)
    if (!used_g[i])
      for (j = 0; j < n; j++)
        if (!used_s[j] && guess[i] == secret[j]) {
          used_g[i] = used_s[j] = 1;
          c++;
          break;
        }
  *cows = c;
  return b;
}
