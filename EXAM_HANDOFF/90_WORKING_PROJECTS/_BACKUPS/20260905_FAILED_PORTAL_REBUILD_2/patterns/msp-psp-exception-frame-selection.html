How to recognize it

Wrapper must find the interrupted hardware frame.

When not to use it

Always choosing MSP fails for PSP thread mode.

Inputs and outputs

Do not replace exception-return semantics with ordinary BX caller logic.

Solving method

TEXT
1. Inspect EXC_RETURN stack-select bit
2. read matching stack pointer
3. pass frame to dispatcher

Worked trace

EXC_RETURN bit2=0 -> MSP; bit2=1 -> PSP.

C approach

Make the contract explicit in types and parameters. Do not replace exception-return semantics with ordinary BX caller logic.

Assembly considerations

Map this contract to registers, memory widths, and the frame before translating the steps. Always choosing MSP fails for PSP thread mode.

Adaptation checklist

Do not replace exception-return semantics with ordinary BX caller logic.

Boundary tests

both stack selections; untouched stacked LR/PC/xPSR.

Common mistakes

Always choosing MSP fails for PSP thread mode. Use the trace above to locate the first differing step.

Baseline: svc frame

SVC #7 with MSP/PSP frame selection and a C dispatcher.

Debugger: svc_result=7 and returned=8. Assembly owns SVC_Handler; EXAM_ENABLE_SVC_HANDLER stays0.

Resource and owner
SVC_Handler selects stacked MSP/PSP frame and tail-calls API decoder

Entry: main. Relevant functions: exam_svc_dispatch, main, SVC_Handler, invoke_service. All final files follow; keep a single definition of each IRQ.

#include "exam_api.h"
volatile uint32_t svc_result;
void exam_svc_dispatch(uint8_t service_number, exam_exception_frame_t *frame) {
  svc_result=service_number;frame->r0=service_number+1u;
}
extern uint32_t invoke_service(void);
volatile uint32_t returned;
int main(void){exam_init();returned=invoke_service();for (;;) {}}

        AREA |.text.pattern_svc|, CODE, READONLY
        THUMB
        PRESERVE8
        IMPORT exam_svc_capture_from_exception
        EXPORT SVC_Handler
SVC_Handler PROC
        TST LR,#4
        ITE EQ
        MRSEQ R0,MSP
        MRSNE R0,PSP
        B exam_svc_capture_from_exception
        ENDP
        EXPORT invoke_service
invoke_service PROC
        SVC #7
        BX LR
        ENDP
        END
