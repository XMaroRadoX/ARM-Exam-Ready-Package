Problem and contract

Exam question

Write a C function and matching ARMASM subroutine named rotate_right_u32 to rotate a 32-bit word right. Use the exact interface below, obey the stated failure behaviour, and preserve the AAPCS register and stack rules.

Normalize amount modulo 32 and rotate without losing bits. A zero or multiple-of-32 amount returns the original word.

C interface

CODE
uint32_t rotate_right_u32(uint32_t value, uint32_t amount)

Register map

FunctionArgumentEntry location
rotate_right_u32uint32_t valueR0
rotate_right_u32uint32_t amountR1

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Keep the low five amount bits.
  2. Combine opposite logical shifts in C.
  3. Use the ARM rotate instruction with the equivalent direction.

Worked trace

Rotating 0x12345678 by 4 produces 0x81234567u.

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
/* Exam prompt: Rotate a 32-bit word right
 * Contract: Normalize amount modulo 32 and rotate without losing bits. A zero or
 * multiple-of-32 amount returns the original word. Method:
 * 1. Keep the low five amount bits.
 * 2. Combine opposite logical shifts in C.
 * 3. Use the ARM rotate instruction with the equivalent direction.
 */
uint32_t rotate_right_u32(uint32_t value, uint32_t amount) {
  amount &= 31u;
  return amount ? (value >> amount) | (value << (32u - amount)) : value;
}

Common exam mistakes

  • Allowing a bit index outside 0 through 31 or shifting by a full word width.
  • Using signed shifts when the task is defined on a uint32_t bit pattern.
  • Packing bytes in the opposite order from the stated most-significant-byte-first contract.

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
