Test whether a matrix is an identity matrix

Problem and contract

Exam question

Write a C function and matching ARMASM subroutine named matrix_is_identity_i32 to test whether a matrix is an identity matrix. Use the exact interface below, obey the stated failure behaviour, and preserve the AAPCS register and stack rules.

Return 1 when diagonal cells are one and every other cell is zero. size must be at most 256. The empty 0x0 matrix is accepted; a null nonempty matrix is invalid and returns 0.

C interface

CODE
int matrix_is_identity_i32(const int32_t *matrix, uint32_t size)

Register map

FunctionArgumentEntry location
matrix_is_identity_i32const int32_t *matrixR0
matrix_is_identity_i32uint32_t sizeR1

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Visit every row and column.
  2. Expect one when row equals column.
  3. Expect zero everywhere else.

Worked trace

[[1,0,0],[0,1,0],[0,0,1]] passes; changing any off-diagonal zero fails.

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
/* Exam prompt: Test whether a matrix is an identity matrix
 * Contract: Return 1 when diagonal cells are one and every other cell is zero. size
 * must be at most 256. The empty 0x0 matrix is accepted; a null nonempty matrix is
 * invalid and returns 0. Method:
 * 1. Visit every row and column.
 * 2. Expect one when row equals column.
 * 3. Expect zero everywhere else.
 */
int matrix_is_identity_i32(const int32_t *matrix, uint32_t size) {
  if (size > 256 || (!matrix && size))
    return 0;
  for (uint32_t row = 0; row < size; ++row)
    for (uint32_t column = 0; column < size; ++column)
      if (matrix[row * size + column] != (row == column ? 1 : 0))
        return 0;
  return 1;
}

int test_main(void) {
  int32_t a[] = {1, 0, 0, 0, 1, 0, 0, 0, 1};
  CHECK(matrix_is_identity_i32(a, 3));
  a[1] = 2;
  CHECK(!matrix_is_identity_i32(a, 3));
  CHECK(matrix_is_identity_i32(0, 0));
  CHECK(!matrix_is_identity_i32(a, 257));
  return 0;
}

Common exam mistakes

  • Using row times rows plus column instead of row times columns plus column.
  • Ignoring zero dimensions, rectangular shapes or a selected row or column bound.
  • Partially modifying the output before a capacity or arithmetic preflight has passed.

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
