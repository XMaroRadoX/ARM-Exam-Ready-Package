Understand the idea

The eight LEDs are outputs controlled by a byte mask. Logical index 0 maps to physical LED11, and index 7 maps to LED4. A bit value of one in the API display mask means on. Do not use the printed LED number directly as the logical index.

A whole-byte write replaces the display pattern. Individual on/off/toggle helpers affect one logical LED. one_hot clears the others and lights one LED. Separate a mathematical result from its encoded display: first inspect the result, then test the bit layout independently.

When a question mentions 'most significant digit', draw the physical LED order. Paper wording about number representation can invert the mapping you first expect.

Worked example

Illustrative fragment unless explicitly marked as a complete project below. Read the contract and required placement before copying.

C
exam_led_write(0x81u);
/* Physical LED4 and LED11 on; other six off. */
(void)exam_led_one_hot(2u);
/* Only physical LED9 on. */

Execution trace

0x81 sets bits 7 and 0 → LED4 and LED11. one_hot(2) replaces that display with bit 2 only.

Try it before the answer

Display binary 10 on the least significant four LEDs while clearing the others.

Hint 1

Decimal 10 is binary 1010.

Hint 2

Logical bits 0..3 correspond to LED11..LED8.

Reveal the worked answer

exam_led_write(0x0Au) turns on LED10 and LED8. Inspect these physical outputs separately before integrating the algorithm.

Common mistakes and symptoms

Passing 11 to an index helper is out of range. Toggling when a full write was intended retains stale bits.

Checkpoint

Predict the exact physical LEDs for masks 0x01,0x80,0x55.

Deeper explanation and source examples

Continue into the maintained reference chapter

API indexes 0 through 7 correspond to GPIO bits P2.0 through P2.7 and physical labels LED11 down to LED4. For a physical label, use index 11 - label.

Show C code
C
exam_led_on(7u);       /* LED4 */
exam_led_one_hot(3u);  /* only LED8; returns EXAM_OK, not a bit mask */
exam_led_write(0x81u); /* LED4 and LED11 */

Check the returned status for indexed calls. exam_led_write() writes the full logical byte atomically; exam_led_read() returns that logical byte and exam_led_clear() turns all eight off.
