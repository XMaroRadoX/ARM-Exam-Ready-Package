How to recognize it

Wrapper must find the interrupted hardware frame.

When not to use it

Always choosing MSP fails for PSP thread mode.

Inputs and outputs

Do not replace exception-return semantics with ordinary BX caller logic.

Solving method

TEXT
1. Inspect EXC_RETURN stack-select bit
2. read matching stack pointer
3. pass frame to dispatcher

Worked trace

EXC_RETURN bit2=0 -> MSP; bit2=1 -> PSP.

C approach

Make the contract explicit in types and parameters. Do not replace exception-return semantics with ordinary BX caller logic.

Assembly considerations

Map this contract to registers, memory widths, and the frame before translating the steps. Always choosing MSP fails for PSP thread mode.

Adaptation checklist

; Rare/dangerous template: SVC immediate decode and stacked-R0 result.
; Enable exact SVC ownership before defining this handler.

                AREA    |.text|, CODE, READONLY
                PRESERVE8
                THUMB
                EXPORT  SVC_Handler

SVC_Handler     PROC
                TST     LR, #4
                ITE     EQ
                MRSEQ   R0, MSP
                MRSNE   R0, PSP
                LDR     R1, [R0, #24]
                LDRB    R1, [R1, #-2]
                CMP     R1, #50
                BNE     svc_invalid
                LDR     R2, [R0]
                ADDS    R2, R2, #1
                STR     R2, [R0]
                BX      LR
svc_invalid     MOVS    R2, #0
                MVNS    R2, R2
                STR     R2, [R0]
                BX      LR
                ENDP

                END
