Bitfield insertion without neighbor damage

Clear only the destination mask, then OR the masked shifted value.

Routine for this variation: algorithm_bitfield_insertion_without_neighbor_damage. The downloadable file also includes its related helpers and variants.

This page shares its source implementation with related variants; it is not an additional independent implementation.

Problem and contract

Insert/extract only fields fitting within 32 bits. Invalid insertion leaves the word unchanged; invalid extraction returns zero. Packing combines two unsigned halfwords.

A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Validate shift/width.
  2. Construct width mask.
  3. Clear destination field.
  4. Insert masked value.
  5. Reverse with shift-and-mask extraction.

Worked trace

Insert value 3 into a zero word at shift 4,width 2 -> 0x30.

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

/*
 * Exam-study reference: Bitfield extraction insertion and packing.
 * Recognition cue: mask shift pack unpack field.
 *
 * Contract rules:
 * - Fixed-width types make width and signedness part of the interface.
 * - A pointer never carries its length; count/capacity arguments are explicit.
 * - const input objects are not mutated. Non-const outputs may be changed only
 *   within their documented bounds.
 * - Invalid, empty, duplicate and arithmetic-limit behavior is executable in
 *   pattern_edge_vectors() and described in the adjacent README.
 *
 * Trace the validation step first, then the main loop/recurrence invariant,
 * then the final result or capacity check. Public suffix functions are named
 * variants of the same advertised pattern, not unrelated shortcuts.
 */

/* Primary algorithm and its named variants. */

static uint32_t
algorithm_bitfield_insertion_without_neighbor_damage_mask(uint32_t width) {
  if (width == 0u) {
    return 0u;
  }
  return (width >= 32u) ? UINT32_MAX : (UINT32_C(1) << width) - 1u;
}

uint32_t algorithm_bitfield_insertion_without_neighbor_damage(uint32_t word,
                                                              uint32_t value,
                                                              uint32_t shift,
                                                              uint32_t width) {
  uint32_t field_mask;

  if ((width == 0u) || (shift >= 32u) || (width > 32u - shift)) {
    return word;
  }
  field_mask = algorithm_bitfield_insertion_without_neighbor_damage_mask(width)
               << shift;
  return (word & ~field_mask) | ((value << shift) & field_mask);
}

uint32_t algorithm_bitfield_insertion_without_neighbor_damage_extract(uint32_t word,
                                                                      uint32_t shift,
                                                                      uint32_t width) {
  if ((width == 0u) || (shift >= 32u) || (width > 32u - shift)) {
    return 0u;
  }
  return (word >> shift) &
         algorithm_bitfield_insertion_without_neighbor_damage_mask(width);
}

uint32_t algorithm_bitfield_insertion_without_neighbor_damage_pack_u16(uint16_t high,
                                                                       uint16_t low) {
  return ((uint32_t)high << 16u) | low;
}

  if (!pattern_core_vector())
    return __LINE__;
  if (!pattern_edge_vectors())
    return __LINE__;

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
