Floyd-Warshall all-pairs paths

In-place distance matrix, n<=256, positive infinity sentinel. Finite distances must be less than infinity; initialize diagonal to zero. Candidates at or above infinity remain unrepresentable. Return 0 on invalid input, signed overflow or negative cycle, possibly after partial updates.

Problem and contract

In-place distance matrix, n<=256, positive infinity sentinel. Finite distances must be less than infinity; initialize diagonal to zero. Candidates at or above infinity remain unrepresentable. Return 0 on invalid input, signed overflow or negative cycle, possibly after partial updates.

C interface

CODE
int floyd_warshall(int *distance, size_t n, int infinity)

Register map

FunctionArgumentEntry location
floyd_warshallint *distanceR0
floyd_warshallsize_t nR1
floyd_warshallint infinityR2

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. For each intermediate k, visit all pairs i,j.
  2. Skip unreachable legs.
  3. Add finite legs with overflow checking and improve the distance.

Worked trace

0->1=4,1->2=-2,0->2=9: after intermediate 1, distance 0->2 becomes 2.

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
int floyd_warshall(int *d, size_t n, int inf) {
  if (!d || n > 256 || inf <= 0)
    return 0;
  for (size_t k = 0; k < n; k++)
    for (size_t i = 0; i < n; i++)
      for (size_t j = 0; j < n; j++)
        if (d[i * n + k] != inf && d[k * n + j] != inf) {
          int64_t x = (int64_t)d[i * n + k] + d[k * n + j];
          if (x < INT_MIN || x > INT_MAX)
            return 0;
          if (x < d[i * n + j])
            d[i * n + j] = (int)x;
        }
  for (size_t i = 0; i < n; i++)
    if (d[i * n + i] < 0)
      return 0;
  return 1;
}

#define CHECK(x) do { if (!(x)) return __LINE__; } while (0)
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
int floyd_warshall(int *distance, size_t n, int infinity);
int test_main(void) {
  int d[] = {0, 4, 9, 999, 0, -2, 999, 999, 0};
  CHECK(floyd_warshall(d, 3, 999) && d[2] == 2 && d[3] == 999);
  int cyc[] = {0, -1, -1, 0};
  CHECK(!floyd_warshall(cyc, 2, 999));
  int big[] = {0, INT_MAX - 1, INT_MAX - 1, 0};
  CHECK(!floyd_warshall(big, 2, INT_MAX));
  return 0;
}

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
