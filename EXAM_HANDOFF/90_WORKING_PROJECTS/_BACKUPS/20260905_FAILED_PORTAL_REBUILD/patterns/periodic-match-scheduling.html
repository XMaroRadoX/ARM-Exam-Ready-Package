How to recognize it

Maintain repeated timing over many intervals.

When not to use it

Resetting from delayed foreground can accumulate drift.

Inputs and outputs

State whether to catch up, drop, or count missed deadlines.

Solving method

TEXT
1. Choose reset-on-match or advance compare from previous deadline
2. acknowledge
3. bound delayed catch-up

Worked trace

deadlines100,200,300 remain scheduled even if servicing at205.

C approach

Make the contract explicit in types and parameters. State whether to catch up, drop, or count missed deadlines.

Assembly considerations

Map this contract to registers, memory widths, and the frame before translating the steps. Resetting from delayed foreground can accumulate drift.
