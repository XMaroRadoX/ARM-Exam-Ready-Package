How to recognize it

Repeated table samples form a timed waveform.

When not to use it

Coalescing flags can lose required sample ticks.

Inputs and outputs

Distinguish sample rate from waveform frequency.

Solving method

TEXT
1. Initialize DAC
2. choose sample frequency
3. write one sample per tick
4. wrap index
5. silence on stop

Worked trace

4 samples at4kHz -> waveform1kHz.

C approach

Make the contract explicit in types and parameters. Distinguish sample rate from waveform frequency.

Assembly considerations

Map this contract to registers, memory widths, and the frame before translating the steps. Coalescing flags can lose required sample ticks.

Adaptation checklist
