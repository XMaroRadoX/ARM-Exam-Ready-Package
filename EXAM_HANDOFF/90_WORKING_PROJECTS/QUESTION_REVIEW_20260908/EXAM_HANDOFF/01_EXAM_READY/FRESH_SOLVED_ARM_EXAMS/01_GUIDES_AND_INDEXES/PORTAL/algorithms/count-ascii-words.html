Problem and contract

Exam question

Write a C function and matching ARMASM subroutine named string_count_ascii_words to count ascii words. Use the exact interface below, obey the stated failure behaviour, and preserve the AAPCS register and stack rules.

Count maximal runs of non-whitespace bytes. ASCII space, tab, line feed, vertical tab, form feed, and carriage return are separators. Return -1 for null or unterminated input.

C interface

CODE
int32_t string_count_ascii_words(const uint8_t *text, uint32_t capacity)

Register map

FunctionArgumentEntry location
string_count_ascii_wordsconst uint8_t *textR0
string_count_ascii_wordsuint32_t capacityR1

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Validate NUL within capacity.
  2. Track whether the scan is inside a word.
  3. Increment only when a non-space byte begins a new word.

Worked trace

For " ARM\tC ASM\n", word starts occur at A, C, and A, so the result is 3.

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
/* Exam prompt: Count ASCII words
 * Contract: Count maximal runs of non-whitespace bytes. ASCII space, tab, line feed,
 * vertical tab, form feed, and carriage return are separators. Return -1 for null or
 * unterminated input. Method:
 * 1. Validate NUL within capacity.
 * 2. Track whether the scan is inside a word.
 * 3. Increment only when a non-space byte begins a new word.
 */
static int ascii_space(uint8_t c) { return c == ' ' || (c >= '\t' && c <= '\r'); }
int32_t string_count_ascii_words(const uint8_t *text, uint32_t capacity) {
  if (!text)
    return -1;
  uint32_t length = 0;
  while (length < capacity && text[length])
    ++length;
  if (length == capacity || length > INT32_MAX)
    return -1;
  uint32_t words = 0;
  int inside = 0;
  for (uint32_t i = 0; i < length; ++i) {
    int space = ascii_space(text[i]);
    if (!space && !inside)
      ++words;
    inside = !space;
  }
  return (int32_t)words;
}

Common exam mistakes

  • Dereferencing the data pointer before handling the documented empty-input case.
  • Using a result or accumulator width that is too small for the stated range.
  • Writing the output before every pointer, count and overflow condition has been validated.

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
