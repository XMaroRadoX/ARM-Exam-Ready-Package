12. IRQ-to-main events

Short handlers, event flags, volatile data, and critical sections.

Jump to code ↓

ButtonsEINTAcknowledgementEvent FlagsCritical Sections

exam_events_set() is suitable for publishing bit events from a handler. Foreground code atomically consumes selected bits with exam_events_take().

Show C code
C
enum { EVENT_SAMPLE = 1u << 0 };

void TIMER0_IRQHandler(void)
{
  if ((exam_timer_ack(EXAM_TIMER0) & 1u) != 0u) {
    exam_events_set(EVENT_SAMPLE);
  }
}

Use volatile for asynchronously changed objects. Protect a compound snapshot with exam_critical_enter() and exam_critical_exit(), then do slow work after leaving the critical section.
