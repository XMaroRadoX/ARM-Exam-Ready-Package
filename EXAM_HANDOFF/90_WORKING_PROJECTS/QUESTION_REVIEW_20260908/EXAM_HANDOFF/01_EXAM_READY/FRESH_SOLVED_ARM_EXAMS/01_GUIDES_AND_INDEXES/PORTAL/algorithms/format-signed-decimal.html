Signed decimal formatting

Problem and contract

Write signed decimal text plus a zero terminator. Return character count excluding the terminator, or 0 before output writes for null or insufficient capacity. INT32_MIN is supported.

C interface

CODE
uint32_t format_i32(int32_t value, char *out, uint32_t capacity)

Register map

FunctionArgumentEntry location
format_i32int32_t valueR0
format_i32char *outR1
format_i32uint32_t capacityR2

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Form the unsigned magnitude without signed negation overflow.
  2. Collect digits backwards in a 12-byte scratch buffer.
  3. Check capacity, then emit sign and reversed digits.

Worked trace

-120: scratch digits 0,2,1; output "-120", length 4, capacity at least 5.

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
uint32_t format_i32(int32_t v, char *out, uint32_t cap) {
  char d[12];
  uint32_t x = v < 0 ? (uint32_t)(-(int64_t)v) : (uint32_t)v, n = 0, k = 0;
  do {
    d[n++] = (char)(48 + x % 10);
    x /= 10;
  } while (x);
  uint32_t len = n + (v < 0);
  if (!out || cap <= len)
    return 0;
  if (v < 0)
    out[k++] = 45;
  while (n)
    out[k++] = d[--n];
  out[k] = 0;
  return k;
}

#define CHECK(x) do { if (!(x)) return __LINE__; } while (0)

  char s[13] = {0};
  s[12] = 77;
  CHECK(format_i32(INT32_MIN, s, 12) == 11 && s[0] == 45 && s[10] == 56 && s[11] == 0 &&
        s[12] == 77);
  s[0] = 88;
  CHECK(!format_i32(-120, s, 4) && s[0] == 88);
  CHECK(format_i32(0, s, 2) == 1 && s[0] == 48 && s[1] == 0);
  return 0;
}

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
