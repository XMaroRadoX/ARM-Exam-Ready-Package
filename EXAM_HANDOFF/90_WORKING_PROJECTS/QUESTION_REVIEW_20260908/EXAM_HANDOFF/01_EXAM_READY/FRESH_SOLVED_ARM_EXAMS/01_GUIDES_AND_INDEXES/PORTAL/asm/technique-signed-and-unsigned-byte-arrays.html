How to recognize it

Data elements occupy one byte.

When not to use it

Word loads may read unrelated elements and beyond bounds.

Inputs and outputs

Byte size and signed interpretation are separate choices.

Solving method

TEXT
TEXT
1. Select LDRSB or LDRB
2. compare with matching signedness
3. store STRB
4. increment by1

Worked trace

0xFE -> LDRSB=-2; LDRB=254.

C approach

Make the contract explicit in types and parameters. Byte size and signed interpretation are separate choices.

Assembly considerations

Map this contract to registers, memory widths, and the frame before translating the steps. Word loads may read unrelated elements and beyond bounds.

Adaptation checklist

Byte size and signed interpretation are separate choices.

Boundary tests

0x00,0x7F,0x80,0xFF; one byte.

Common mistakes

; Recommended exam template: read matrix[row][column] from a byte matrix.
; C prototype: uint8_t matrix_get_u8(const uint8_t *base,
;                                   uint32_t row, uint32_t columns,
;                                   uint32_t column);
; Offset = row * columns + column. No bounds check in this low-level pattern.

                AREA    |.text|, CODE, READONLY
                PRESERVE8
                THUMB
                EXPORT  matrix_get_u8

matrix_get_u8   PROC
                MUL     R1, R1, R2
                ADDS    R1, R1, R3
                LDRB    R0, [R0, R1]
                BX      LR
                ENDP

                END
