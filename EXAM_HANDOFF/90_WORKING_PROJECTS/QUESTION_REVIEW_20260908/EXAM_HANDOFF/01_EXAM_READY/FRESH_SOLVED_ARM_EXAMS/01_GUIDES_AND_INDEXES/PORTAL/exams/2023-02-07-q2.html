2023-02-07 Sort FreeRunning Timer — Q2

Capture characters with INT0 using Timer1 and alternate LEDs 6/7; KEY1 sorts and lights LED11.

Hardware: LED · Buttons · Timer1

Review complete within the stated contract and limitations

Exact contract

Timer1 resets at MR0=0xFF with no match interrupt. Each accepted INT0 interrupt stores its low byte as signed data, up to MAX_VALUES=20. KEY1 sorts the initialized prefix and then lights physical LED11.

Original paper — page 2

Solution reasoning

  1. Keep a count independent of array capacity.
  2. Alternate LED6 and LED7 only after a successful capture.
  3. On KEY1, clear LEDs 6/7, call insertionSort(values, count), then signal completion.

Worked trace

  1. Capture 0xFE: values[0]=-2, LED6 on.
  2. Capture 0x03: values[1]=3, LED7 on.
  3. KEY1 sorts [-2, 3] and lights LED11. Capture 21 is ignored once 20 slots are filled.

C
/* Exam of 7 February 2023, questions 1 and 2. */
#include <stdint.h>
#include "LPC17xx.h"

/* Single-LED API arguments are physical board labels LD4 through LD11. */
#include "exam_api.h"

#define MAX_VALUES 20u

extern void copyData(const int8_t *source, int8_t *destination,
                     uint32_t length);
extern void insertionSort(int8_t *values, uint32_t length);

static int8_t values[MAX_VALUES];
static uint32_t value_count;
static uint32_t show_led6 = 1u;

void EINT0_IRQHandler(void)
{
  exam_button_ack(EXAM_BUTTON_INT0);

  if (value_count < MAX_VALUES) {
    values[value_count] = (int8_t)exam_timer_read(EXAM_TIMER1);
    value_count++;

    if (show_led6) {
      (void)exam_led_on(6u);  /* physical LED6 */
      (void)exam_led_off(7u); /* physical LED7 */
    } else {
      (void)exam_led_off(6u);
      (void)exam_led_on(7u);
    }
    show_led6 ^= 1u;
  }
}

void EINT1_IRQHandler(void)
{
  exam_button_ack(EXAM_BUTTON_KEY1);
  (void)exam_led_off(6u);
  (void)exam_led_off(7u);
  insertionSort(values, value_count);
  (void)exam_led_on(11u); /* physical LED11 */
}

int main(void)
{
  exam_init();
  exam_buttons_init();
  /* Timer1 resets at 0xFF, but its match does not generate an interrupt. */
  (void)exam_timer_config_ticks(EXAM_TIMER1, 0xFFu,
                                EXAM_TIMER_MODULO_NO_IRQ);
  exam_timer_start(EXAM_TIMER1);

  for (;;) {
    __WFI();
  }
}

; void copyData(const int8_t *source, int8_t *destination, uint32_t length)
copyData        PROC
                CMP     R2, #0
                BEQ     copy_done
copy_loop
                LDRB    R3, [R0], #1
                STRB    R3, [R1], #1
                SUBS    R2, R2, #1
                BNE     copy_loop
copy_done
                BX      LR
                ENDP

; void insertionSort(int8_t *values, uint32_t length)
; Signed byte loads make negative values sort correctly.
insertionSort   PROC
                PUSH    {R4-R8, LR}
                MOV     R4, R0          ; Base address.
                MOV     R5, R1          ; Array length.
                CMP     R5, #1
                BLS     sort_done

                MOVS    R6, #1          ; i = 1.
sort_outer
                CMP     R6, R5
                BHS     sort_done

                LDRSB   R7, [R4, R6]    ; x = A[i].
                SUBS    R8, R6, #1      ; j = i - 1.

sort_inner
                CMP     R8, #0
                BLT     sort_insert
                LDRSB   R0, [R4, R8]
                CMP     R0, R7
                BLE     sort_insert

                ADDS    R1, R8, #1
                STRB    R0, [R4, R1]
                SUBS    R8, R8, #1
                B       sort_inner

sort_insert
                ADDS    R8, R8, #1
                STRB    R7, [R4, R8]
                ADDS    R6, R6, #1
                B       sort_outer

sort_done
                POP     {R4-R8, PC}
                ENDP

                LTORG
                ALIGN   4
                END

Code explanation

  • The cast to int8_t supplies the signed interpretation required by Q1.
  • The paper places sorting in the button handler; the generic advice to move all computation out of IRQs would change this answer.

Complexity and memory

O(1) capture; O(k²) sort for k<=20; 20 bytes of sample storage.

Relevant mistakes

  • Sorting all 20 slots includes uninitialized samples.
  • Passing 2 to the single-LED helper does not mean physical LED6.

Paper interpretation and limits

  • One raw external interrupt is treated as one press. Mechanical bounce and sorting latency require board checks; no debounce period is prescribed in this paper.

Review findings and corrections

  • Reviewed the original contract and current implementation; no additional implementation defect found within the documented domain.
