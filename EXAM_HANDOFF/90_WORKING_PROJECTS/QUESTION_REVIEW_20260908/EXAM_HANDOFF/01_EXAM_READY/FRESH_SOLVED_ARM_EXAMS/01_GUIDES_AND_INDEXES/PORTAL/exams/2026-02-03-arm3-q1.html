Question · 2026-02-03 · ARM 3 Recaman ADC Timer

Algorithms: Arrays · Recurrence

Review complete within the stated contract and limitations

Exact contract

void Recaman(uint32_t *area, uint8_t n): R0=output words, R1=length 0..255. Write n terms starting a 0=0. For index i>0, use previous-i only if positive and absent from all earlier terms; otherwise use previous+i.

Original paper — page 2

Solution reasoning

  1. Return immediately for length 0.
  2. For each new index, test the subtraction candidate against zero and scan the previously written prefix.
  3. Only the subtraction branch checks uniqueness; the addition branch may repeat a value.

Worked trace

  1. n8 ->[0, 1, 3, 6, 2, 7, 13, 20].
  2. At i4, 6-4=2 is positive and unseen, so store 2.
  3. At i5, 2-5 is negative, so store 7.
  4. The longer sequence legitimately contains42 more than once.

ASSEMBLY
                AREA    |.text|, CODE, READONLY
                PRESERVE8
                THUMB

                EXPORT  Recaman

; void Recaman(uint32_t *area, uint8_t n)
Recaman         PROC
                PUSH    {R4-R10, LR}
                MOV     R4, R0
                UXTB    R5, R1
                CMP     R5, #0
                BEQ     recaman_done

                MOVS    R6, #0
                STR     R6, [R4]        ; a0 = 0.
                MOVS    R6, #1          ; n = 1.

recaman_loop
                CMP     R6, R5
                BHS     recaman_done

                SUBS    R7, R6, #1
                LDR     R8, [R4, R7, LSL #2]
                SUBS    R9, R8, R6      ; Candidate = previous - n.
                CMP     R9, #0
                BLE     recaman_add

                MOVS    R7, #0
recaman_search
                CMP     R7, R6
                BHS     recaman_use_candidate
                LDR     R10, [R4, R7, LSL #2]
                CMP     R10, R9
                BEQ     recaman_add
                ADDS    R7, R7, #1
                B       recaman_search

recaman_use_candidate
                STR     R9, [R4, R6, LSL #2]
                B       recaman_next

recaman_add
                ADDS    R9, R8, R6
                STR     R9, [R4, R6, LSL #2]

recaman_next
                ADDS    R6, R6, #1
                B       recaman_loop

recaman_done
                POP     {R4-R10, PC}
                ENDP

                LTORG
                ALIGN   4
                END

Code explanation

  • UXTB enforces the uint8_t length and LSL#2 addresses words.
  • R6 is the mathematical index i; the linear scan never reads beyond the already initialized prefix.

Complexity and memory

O(n²) searches, n output words, 32-byte register frame.

Relevant mistakes

  • Rejecting repeated sums changes Recamán’s definition.
  • Allowing a zero subtraction result violates the paper’s positive condition.
  • Reserving255 bytes is insufficient for 255 words.
