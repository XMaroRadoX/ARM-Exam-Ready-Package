# Exam-Ready Resources

Start with the package [`START_HERE.html`](../START_HERE.html).

- `FRESH_SOLVED_ARM_EXAMS` is the primary searchable solution and learning
  library created from the original papers.
- `02_STARTING_TEMPLATES/Official Combined Exam API` is the canonical clean
  API starting project. Open `sample.uvprojx`; write the exam program in
  `Source/sample.c` and use only declarations present in
  `Source/exam_api/exam_api.h`.
Always copy a starting project into `../90_WORKING_PROJECTS` before editing it.
