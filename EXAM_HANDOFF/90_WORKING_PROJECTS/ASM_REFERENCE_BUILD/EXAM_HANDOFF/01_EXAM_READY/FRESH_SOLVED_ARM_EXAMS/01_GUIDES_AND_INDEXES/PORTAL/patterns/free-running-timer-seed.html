How to recognize it

Sample timing-dependent counter as a seed.

When not to use it

A modulo counter is not full-range free-running.

Inputs and outputs

Do not claim statistical randomness or reset counter on every read.

Solving method

TEXT
1. Choose counter mode/range
2. start once
3. capture required instant
4. apply requested seed mapping

C approach

Make the contract explicit in types and parameters. Do not claim statistical randomness or reset counter on every read.

Assembly considerations

Map this contract to registers, memory widths, and the frame before translating the steps. A modulo counter is not full-range free-running.

/* Recommended exam template: free-running timer with reset but no IRQ. */
#include "exam_api.h"

exam_status_t free_running_timer_init(void) {
    exam_status_t status;

    status = timer_set_prescaler(1u, 0u);
    if (status != EXAM_OK) return status;

    /* RESET is selected without TIMER_ACTION_INTERRUPT. */
    status = timer_configure_match(1u, 0u, 0xFFFFu, TIMER_ACTION_RESET);
    if (status != EXAM_OK) return status;

    status = timer_reset(1u);
    if (status != EXAM_OK) return status;
    return timer_start(1u);
}

uint32_t free_running_timer_sample(void) {
    return timer_read_counter(1u);
}
