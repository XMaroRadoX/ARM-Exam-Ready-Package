1. Project, main(), and waiting

Start from zero with the sole Official Combined project.

Jump to code ↓
On this pageCanonical contract

Start with sample.uvprojx. Put foreground code in Source/sample.c and assembly in Source/ASM_funct.s. Edit an existing IRQ source when the question needs that vector; never add a second definition of the same handler. When using a complete maintained solved answer, keep its handlers and static state together in sample.c and remove conflicting template handler definitions as described in the integration guide.

Show C code
C
#include "LPC17xx.h"
#include "exam_api.h"

int main(void)
{
  exam_init();
  /* Initialize only the peripherals named by the paper. */
  for (;;) {
    __WFI();
  }
}

exam_init() prepares the core support and LEDs. It does not start every timer, RIT, SysTick, ADC conversion, button debounce, or joystick workflow.
