Left array rotation by reversal

Reverse the two segments, then reverse the complete array.

Complexity
O(n) time; O(1) for reversal or O(n) caller scratch.

Routine for this variation: algorithm_left_array_rotation_by_reversal. The downloadable file also includes its related helpers and variants.

This page shares its source implementation with related variants; it is not an additional independent implementation.

Problem and contract

Normalize rotation modulo count. Left/right variants mutate in place; scratch rotation requires disjoint scratch_count>=count.

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Normalize k.
  2. Reverse the first and second regions.
  3. Reverse the whole array.
  4. Derive right rotation or use scratch mapping.

Worked trace

[1,2,3,4], left 1 -> [2,3,4,1]; right 1 -> [4,1,2,3].

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

/*
 * Exam-study reference: Left and right array rotation.
 * Recognition cue: rotate array using reversal.
 *
 * Contract rules:
 * - Fixed-width types make width and signedness part of the interface.
 * - A pointer never carries its length; count/capacity arguments are explicit.
 * - const input objects are not mutated. Non-const outputs may be changed only
 *   within their documented bounds.
 * - Invalid, empty, duplicate and arithmetic-limit behavior is executable in
 *   pattern_edge_vectors() and described in the adjacent README.
 *
 * Trace the validation step first, then the main loop/recurrence invariant,
 * then the final result or capacity check. Public suffix functions are named
 * variants of the same advertised pattern, not unrelated shortcuts.
 */

/* Primary algorithm and its named variants. */

static void algorithm_left_array_rotation_by_reversal_reverse_range(int32_t *values,
                                                                    uint32_t left,
                                                                    uint32_t right) {
  while (left < right) {
    int32_t temporary = values[left];
    values[left] = values[right];
    values[right] = temporary;
    ++left;
    --right;
  }
}

void algorithm_left_array_rotation_by_reversal(int32_t *values, uint32_t count,
                                               uint32_t positions) {
  if ((values == NULL) || (count < 2u)) {
    return;
  }
  positions %= count;
  if (positions == 0u) {
    return;
  }
  algorithm_left_array_rotation_by_reversal_reverse_range(values, 0u, positions - 1u);
  algorithm_left_array_rotation_by_reversal_reverse_range(values, positions,
                                                          count - 1u);
  algorithm_left_array_rotation_by_reversal_reverse_range(values, 0u, count - 1u);
}

void algorithm_left_array_rotation_by_reversal_right(int32_t *values, uint32_t count,
                                                     uint32_t positions) {
  if (count != 0u) {
    algorithm_left_array_rotation_by_reversal(values, count,
                                              count - (positions % count));
  }
}

int algorithm_left_array_rotation_by_reversal_with_scratch(int32_t *values,
                                                           uint32_t count,
                                                           uint32_t positions,
                                                           int32_t *scratch,
                                                           uint32_t scratch_count) {
  uint32_t index;

  if ((values == NULL) || (scratch == NULL) || (scratch_count < count) ||
      values == scratch) {
    return 0;
  }
  if (count == 0u) {
    return 1;
  }
  positions %= count;
  for (index = 0u; index < count; ++index) {
    scratch[index] = values[index >= count - positions ? index - (count - positions)
                                                       : index + positions];
  }
  for (index = 0u; index < count; ++index) {
    values[index] = scratch[index];
  }
  return 1;
}

static int pattern_core_vector(void) {
  int32_t a[] = {1, 2, 3, 4};
  algorithm_left_array_rotation_by_reversal(a, 4, 2);
  return a[0] == 3 && a[1] == 4 && a[2] == 1 && a[3] == 2;
}
static int pattern_edge_vectors(void) {
  int32_t a[] = {1, 2, 3, 4}, b[] = {1, 2, 3}, t[3];
  algorithm_left_array_rotation_by_reversal_right(a, 4, 1);
  return a[0] == 4 && a[1] == 1 && a[3] == 3 &&
         algorithm_left_array_rotation_by_reversal_with_scratch(b, 3, 1, t, 3) &&
         b[0] == 2 && b[2] == 1 &&
         !algorithm_left_array_rotation_by_reversal_with_scratch(b, 3, 1, t, 2);
}
int pattern_test_suite(void) {
  if (!pattern_core_vector())
    return __LINE__;
  if (!pattern_edge_vectors())
    return __LINE__;
  return 0;
}
int test_main(void) { return pattern_test_suite(); }

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
