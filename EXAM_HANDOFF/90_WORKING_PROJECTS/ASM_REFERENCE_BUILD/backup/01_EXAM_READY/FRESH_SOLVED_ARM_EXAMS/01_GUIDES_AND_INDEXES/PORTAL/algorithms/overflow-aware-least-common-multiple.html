Overflow-aware least common multiple

Divide by the GCD before multiplying and check the widened product.

Complexity
O(log min(a,b)) time; LCM adds O(1) checked arithmetic.

Routine for this variation: algorithm_overflow_aware_least_common_multiple_lcm. The downloadable file also includes its related helpers and variants.

This page shares its source implementation with related variants; it is not an additional independent implementation.

Problem and contract

Euclidean GCD; gcd(0,0)=0. Checked LCM divides first, then checks multiplication; zero operands produce zero successfully.

A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Repeat Euclidean remainder replacement until second value is zero.
  2. For LCM divide by GCD before checked multiplication.

Worked trace

gcd(12,18)=6; lcm=12/6*18=36.

Matching C

C
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

/*
 * Exam-study reference: Euclidean GCD and overflow-aware LCM.
 * Recognition cue: greatest common divisor least common multiple.
 *
 * Contract rules:
 * - Fixed-width types make width and signedness part of the interface.
 * - A pointer never carries its length; count/capacity arguments are explicit.
 * - const input objects are not mutated. Non-const outputs may be changed only
 *   within their documented bounds.
 * - Invalid, empty, duplicate and arithmetic-limit behavior is executable in
 *   pattern_edge_vectors() and described in the adjacent README.
 *
 * Trace the validation step first, then the main loop/recurrence invariant,
 * then the final result or capacity check. Public suffix functions are named
 * variants of the same advertised pattern, not unrelated shortcuts.
 */

/* Primary algorithm and its named variants. */

uint32_t algorithm_overflow_aware_least_common_multiple(uint32_t first,
                                                        uint32_t second) {
  while (second != 0u) {
    uint32_t remainder = first % second;
    first = second;
    second = remainder;
  }
  return first;
}

int algorithm_overflow_aware_least_common_multiple_lcm(uint32_t first, uint32_t second,
                                                       uint32_t *result) {
  uint32_t divisor;
  uint32_t reduced_first;

  if (result == NULL) {
    return 0;
  }
  if ((first == 0u) || (second == 0u)) {
    *result = 0u;
    return 1;
  }
  divisor = algorithm_overflow_aware_least_common_multiple(first, second);
  reduced_first = first / divisor;
  if (reduced_first > UINT32_MAX / second) {
    return 0;
  }
  *result = reduced_first * second;
  return 1;
}

static int pattern_core_vector(void) {
  return algorithm_overflow_aware_least_common_multiple(48, 18) == 6;

static int pattern_edge_vectors(void) {
  uint32_t l = 9;
  return algorithm_overflow_aware_least_common_multiple(0, 0) == 0 &&
         algorithm_overflow_aware_least_common_multiple(7, 0) == 7 &&
         algorithm_overflow_aware_least_common_multiple_lcm(12, 18, &l) && l == 36 &&
         algorithm_overflow_aware_least_common_multiple_lcm(0, 18, &l) && l == 0 &&
         !algorithm_overflow_aware_least_common_multiple_lcm(UINT32_MAX, 2, &l);
}
int pattern_test_suite(void) {
  if (!pattern_core_vector())
    return __LINE__;
  if (!pattern_edge_vectors())
    return __LINE__;
  return 0;
}
int test_main(void) { return pattern_test_suite(); }

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
