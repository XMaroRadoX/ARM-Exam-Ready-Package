Lower bound insertion position

Maintain a half-open interval and keep the first value not less than the key.

Complexity
O(log n) time, O(1) space.

Routine for this variation: algorithm_lower_bound_insertion_position. The downloadable file also includes its related helpers and variants.

This page shares its source implementation with related variants; it is not an additional independent implementation.

Problem and contract

Ascending signed words. Primary returns lower-bound index in [0,count]; exact returns first matching index or -1. Exact-index results require count<=INT32_MAX.

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Maintain half-open [low,high).
  2. Choose overflow-safe middle.
  3. Discard one half.
  4. Return lower bound.
  5. Verify equality for exact search.

Worked trace

[1,2,2,4], key 2: lower bound=1, exact index=1.

Matching C

/*
 * Exam-study reference: Binary search and lower bound.
 * Recognition cue: sorted array binary search insertion position.
 *
 * Contract rules:
 * - Fixed-width types make width and signedness part of the interface.
 * - A pointer never carries its length; count/capacity arguments are explicit.
 * - const input objects are not mutated. Non-const outputs may be changed only
 *   within their documented bounds.
 * - Invalid, empty, duplicate and arithmetic-limit behavior is executable in
 *   pattern_edge_vectors() and described in the adjacent README.
 *
 * Trace the validation step first, then the main loop/recurrence invariant,
 * then the final result or capacity check. Public suffix functions are named
 * variants of the same advertised pattern, not unrelated shortcuts.
 */

/* Primary algorithm and its named variants. */

uint32_t algorithm_lower_bound_insertion_position(const int32_t *values, uint32_t count,
                                                  int32_t key) {
  uint32_t low = 0u;
  uint32_t high = count;

  if (values == NULL) {
    return 0u;
  }
  while (low < high) {
    uint32_t middle = low + (high - low) / 2u;
    if (values[middle] < key) {
      low = middle + 1u;
    } else {
      high = middle;
    }
  }
  return low;
}

int32_t algorithm_lower_bound_insertion_position_exact(const int32_t *values,
                                                       uint32_t count, int32_t key) {
  uint32_t position = algorithm_lower_bound_insertion_position(values, count, key);
  if ((values != NULL) && (position < count) && (values[position] == key)) {
    return (int32_t)position;
  }
  return -1;
}

static int pattern_core_vector(void) {
  int32_t a[] = {1, 3, 3, 8};
  return algorithm_lower_bound_insertion_position(a, 4, 3) == 1 &&
         algorithm_lower_bound_insertion_position(a, 4, 5) == 3;
}
static int pattern_edge_vectors(void) {
  int32_t a[] = {1, 3, 3, 8};
  return algorithm_lower_bound_insertion_position(a, 0, 2) == 0 &&
         algorithm_lower_bound_insertion_position_exact(a, 4, 3) == 1 &&
         algorithm_lower_bound_insertion_position_exact(a, 4, 5) == -1 &&
         algorithm_lower_bound_insertion_position(NULL, 4, 1) == 0;
}
int pattern_test_suite(void) {
  if (!pattern_core_vector())
    return __LINE__;
  if (!pattern_edge_vectors())
    return __LINE__;
  return 0;
}
int test_main(void) { return pattern_test_suite(); }

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
