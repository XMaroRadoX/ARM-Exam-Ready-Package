Recursive DFS with depth contract

Byte adjacency matrix with n<=256 and caller-initialized seen. Return newly visited count. The public helper validates vertex and depth; recursion depth is bounded by n. The exported visit helper is also shown below; its seen array and adjacency matrix obey the same storage contract.

Problem and contract

Byte adjacency matrix with n<=256 and caller-initialized seen. Return newly visited count. The public helper validates vertex and depth; recursion depth is bounded by n. The exported visit helper is also shown below; its seen array and adjacency matrix obey the same storage contract.

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Reject invalid start.
  2. Mark current vertex.
  3. Recursively visit unseen adjacent vertices while depth is bounded by n.

Worked trace

0->1->2: enter 0,1,2, then return counts 1,2,3.

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

/*
 * Exam-study reference: Recursive DFS with depth contract.
 * Recognition cue: recursive graph traversal bounded depth.
 *
 * Contract rules:
 * - Fixed-width types make width and signedness part of the interface.
 * - A pointer never carries its length; count/capacity arguments are explicit.
 * - const input objects are not mutated. Non-const outputs may be changed only
 *   within their documented bounds.
 * - Invalid, empty, duplicate and arithmetic-limit behavior is executable in
 *   pattern_edge_vectors() and described in the adjacent README.
 *
 * Trace the validation step first, then the main loop/recurrence invariant,
 * then the final result or capacity check. Public suffix functions are named
 * variants of the same advertised pattern, not unrelated shortcuts.
 */

/* Primary algorithm and its named variants. */
uint32_t visit(const uint8_t *a, uint32_t n, uint32_t v, uint8_t *s, uint32_t depth) {
  uint32_t w, c = 1;
  if (!a || !s || v >= n || !depth || depth > n || s[v])
    return 0;
  s[v] = 1;
  for (w = 0; w < n; w++)
    if (a[v * n + w] && !s[w])
      c += visit(a, n, w, s, depth + 1);
  return c;
}
uint32_t algorithm_recursive_dfs_with_depth_contract(const uint8_t *a, uint32_t n,
                                                     uint32_t start, uint8_t *s) {
  return (!a || !s || start >= n || n > 256u) ? 0 : visit(a, n, start, s, 1);
}

static int pattern_core_vector(void) {
  uint8_t a[9] = {0, 1, 0, 1, 0, 1, 0, 1, 0}, s[3] = {0};
  return algorithm_recursive_dfs_with_depth_contract(a, 3, 0, s) == 3;
}
static int pattern_edge_vectors(void) {
  uint8_t a[1] = {0}, s[1] = {0};
  return algorithm_recursive_dfs_with_depth_contract(a, 1, 0, s) == 1 &&
         algorithm_recursive_dfs_with_depth_contract(a, 1, 1, s) == 0 &&
         algorithm_recursive_dfs_with_depth_contract(NULL, 1, 0, s) == 0;
}
int pattern_test_suite(void) {
  if (!pattern_core_vector())
    return __LINE__;
  if (!pattern_edge_vectors())
    return __LINE__;
  return 0;
}
int test_main(void) { return pattern_test_suite(); }

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
