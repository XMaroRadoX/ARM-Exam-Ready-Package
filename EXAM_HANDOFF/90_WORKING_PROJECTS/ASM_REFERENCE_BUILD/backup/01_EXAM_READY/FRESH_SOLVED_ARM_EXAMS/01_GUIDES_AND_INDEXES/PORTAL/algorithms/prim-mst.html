Problem and contract

Undirected symmetric weight matrix with zero meaning no edge; n=1..256. Supply n best words and n used bytes. Return MST weight, or UINT_MAX for invalid input, disconnection or unrepresentable total. UINT_MAX is reserved.

C interface

CODE
unsigned prim_mst(const unsigned *w, size_t n, size_t start, unsigned *best, unsigned char *used)

Register map

FunctionArgumentEntry location

prim_mstunsigned char *used[entry SP]

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Start one vertex at cost zero.
  2. Add the unused vertex with smallest connection cost.
  3. Update neighbor costs and check the accumulated weight.

Worked trace

Triangle weights 0-1=2,1-2=3,0-2=9 -> MST weight 5.

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
unsigned prim_mst(const unsigned *w, size_t n, size_t s, unsigned *b,
                  unsigned char *u) {
  if (!w || !b || !u || s >= n || n > 256)
    return UINT_MAX;
  for (size_t i = 0; i < n; i++) {
    b[i] = UINT_MAX;
    u[i] = 0;
  }
  b[s] = 0;
  unsigned total = 0;
  for (size_t k = 0; k < n; k++) {
    size_t v = n;
    unsigned low = UINT_MAX;
    for (size_t i = 0; i < n; i++)
      if (!u[i] && b[i] < low) {
        low = b[i];
        v = i;
      }
    if (v == n || low >= UINT_MAX - total)
      return UINT_MAX;
    u[v] = 1;
    total += low;
    for (size_t i = 0; i < n; i++)
      if (!u[i] && w[v * n + i] && w[v * n + i] < b[i])
        b[i] = w[v * n + i];
  }
  return total;
}

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
