Threshold hysteresis

Require low<high and a state pointer. While off, turn on at sample>=high; while on, turn off at sample<=low. Retain state inside the band. Return 0 on invalid input, otherwise 1.

Problem and contract

Require low<high and a state pointer. While off, turn on at sample>=high; while on, turn off at sample<=low. Retain state inside the band. Return 0 on invalid input, otherwise 1.

C interface

CODE

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Read the current state.
  2. Apply its corresponding threshold.
  3. Retain state inside the band.

Worked trace

low=10,high=20: samples 21,15,9 -> states 1,1,0.

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
int hysteresis_update(uint16_t sample, uint16_t low, uint16_t high, uint8_t *state) {
  if (state == 0 || low >= high)
    return 0;
  if (*state == 0u && sample >= high)
    *state = 1u;
  else if (*state != 0u && sample <= low)
    *state = 0u;
  return 1;
}

  CHECK(hysteresis_update(21, 10, 20, &s) && s == 1);

}
