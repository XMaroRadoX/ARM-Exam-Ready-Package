Ownership rule

Let C own initialization, interrupts, timers, and peripherals. Give assembly a clear computation with explicit arguments and results unless the question says otherwise.

  1. Write the C prototype.
  2. Map arguments 1–4 to registers and later arguments to the stack.
  3. Preserve required registers and stack alignment.
  4. Return one result in r0 or write through an explicit pointer.
  5. Test the C call with the smallest and largest inputs.
