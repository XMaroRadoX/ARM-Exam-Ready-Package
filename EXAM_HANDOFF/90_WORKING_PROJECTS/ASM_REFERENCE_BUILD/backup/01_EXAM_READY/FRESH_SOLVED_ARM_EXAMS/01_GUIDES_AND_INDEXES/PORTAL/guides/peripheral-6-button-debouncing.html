6. Button debouncing

One confirmed press driven by an explicitly selected time source.

Jump to code ↓
On this pageCanonical contract
ButtonsDebounceTimer0SysTickRITEINTAcknowledgementEvent FlagsPeriodic

Choose one periodic source. This example samples every 10 ms and confirms after 50 ms using RIT.

Show C code
C
exam_buttons_init();
exam_debounce_config(10u, 50u);
exam_rit_config_ms(10u);
exam_rit_start();

void EINT1_IRQHandler(void)
{
  (void)exam_debounce_begin(EXAM_BUTTON_KEY1);
}

void RIT_IRQHandler(void)
{
  exam_rit_ack();
  exam_debounce_tick();
}

Foreground code consumes EXAM_BUTTON_EVENT_KEY1 from exam_button_events_take(). Do not drive the same debounce from two clocks.
