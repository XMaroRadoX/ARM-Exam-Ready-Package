Complete ARM assembly answer

Show complete assembly solution
Open raw Assembly file
ASSEMBLY
                AREA    |.text|, CODE, READONLY
                PRESERVE8
                THUMB

                EXPORT  run_length_encoding

; uint32_t run_length_encoding(uint32_t digits)
run_length_encoding PROC
                PUSH    {R4-R10, LR}
                SUB     SP, SP, #16     ; Reversed decimal digits.
                MOV     R4, SP
                MOV     R5, R0
                MOVS    R6, #0          ; Number of digits.
                MOVS    R10, #10

extract_digits
                UDIV    R7, R5, R10
                MLS     R8, R7, R10, R5
                STRB    R8, [R4, R6]
                ADDS    R6, R6, #1
                MOV     R5, R7
                CMP     R5, #0
                BNE     extract_digits

                SUBS    R6, R6, #1
                LDRB    R7, [R4, R6]    ; Current digit.
                MOVS    R8, #1          ; Run length.
                MOVS    R9, #0          ; Result.

look_loop
                CMP     R6, #0
                BEQ     append_look_run
                SUBS    R6, R6, #1
                LDRB    R5, [R4, R6]
                CMP     R5, R7
                BNE     append_then_continue
                ADDS    R8, R8, #1
                B       look_loop

append_then_continue
                MUL     R9, R9, R10
                ADD     R9, R9, R7
                MUL     R9, R9, R10
                ADD     R9, R9, R8
                MOV     R7, R5
                MOVS    R8, #1
                B       look_loop

append_look_run
                MUL     R9, R9, R10
                ADD     R9, R9, R7
                MUL     R9, R9, R10
                ADD     R9, R9, R8
                MOV     R0, R9
                ADD     SP, SP, #16
                POP     {R4-R10, PC}
                ENDP

                LTORG
                ALIGN   4
                END

Why the important lines are there

Initialization establishes one owner for every peripheral. Callback or IRQ code acknowledges and records only the event. Foreground code performs longer computation and output. Assembly code keeps its public ABI contract and never assumes hidden array lengths.

Complexity and memory

The algorithm tags are Decimal. Loop bounds and storage are fixed by the paper; no dynamic allocation is introduced.

Common wrong answers

  • Changing the required interface to an easier API call.
  • Using a Timer0-Timer2 API helper while that timer is student-owned.
  • Forgetting active-low input logic or write-one-to-clear interrupt acknowledgement.
  • Doing delays, sorting, filtering, or table generation inside an IRQ.
  • Reading the fifth argument at the wrong stack offset after pushing registers.
