Packed matrix row and column addressing

Translate row/column coordinates into a packed bit position before moving the bit.

Problem and contract

Packed 8x8 bit matrix: move bit 8*r+c to bit 8*c+r.

C interface

CODE
uint64_t algorithm_packed_matrix_row_and_column_addressing(uint64_t x);

Register map

FunctionArgumentEntry location
algorithm_packed_matrix_row_and_column_addressinguint64_t xR0:R1

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Clear output.
  2. For every source row and column.
  3. Extract one bit.
  4. Insert it at column,row.
  5. Return packed output.

Worked trace

A bit at (0,1), value 2, moves to (1,0), value 256.

; Handwritten Cortex-M3 Thumb exam reference.
; Verification status is supplied by the simulator/build reports.
; uint64_t algorithm_packed_matrix_row_and_column_addressing(uint64_t packed)
; R0:R1=input, R0:R1=output. Leaf. R4-R9 saved (24-byte frame).
                AREA    |.text.patterns|, CODE, READONLY
                PRESERVE8
                THUMB
                EXPORT  algorithm_packed_matrix_row_and_column_addressing

algorithm_packed_matrix_row_and_column_addressing PROC
                PUSH    {R4-R9}
                MOV     R4, R0
                MOV     R5, R1
                MOVS    R6, #0
                MOVS    R7, #0
                MOVS    R8, #0          ; source bit index 0..63
transpose_loop
                CMP     R8, #32
                BLO     transpose_source_low
                SUB     R1, R8, #32
                LSR     R2, R5, R1
                B       transpose_have_bit
transpose_source_low
                LSR     R2, R4, R8
transpose_have_bit
                TST     R2, #1
                BEQ     transpose_next
                AND     R0, R8, #7      ; source column
                LSR     R1, R8, #3      ; source row
                LSL     R0, R0, #3
                ADD     R9, R0, R1      ; destination = column*8 + row
                MOVS    R2, #1
                CMP     R9, #32
                BLO     transpose_set_low
                SUB     R9, R9, #32
                LSL     R2, R2, R9
                ORR     R7, R7, R2
                B       transpose_next
transpose_set_low
                LSL     R2, R2, R9
                ORR     R6, R6, R2
transpose_next
                ADDS    R8, R8, #1
                CMP     R8, #64
                BNE     transpose_loop
                MOV     R0, R6
                MOV     R1, R7
                POP     {R4-R9}
                BX      LR
                ENDP

                LTORG
                ALIGN   2
                END

/*
 * Exam-study reference: Packed 8x8 bit-matrix transpose.
 * Recognition cue: transpose packed binary matrix rows and columns.
 *
 * Contract rules:
 * - Fixed-width types make width and signedness part of the interface.
 * - A pointer never carries its length; count/capacity arguments are explicit.
 * - const input objects are not mutated. Non-const outputs may be changed only
 *   within their documented bounds.
 * - Invalid, empty, duplicate and arithmetic-limit behavior is executable in
 *   pattern_edge_vectors() and described in the adjacent README.
 *
 * Trace the validation step first, then the main loop/recurrence invariant,
 * then the final result or capacity check. Public suffix functions are named
 * variants of the same advertised pattern, not unrelated shortcuts.
 */

/* Primary algorithm and its named variants. */
uint64_t algorithm_packed_matrix_row_and_column_addressing(uint64_t x) {
  uint64_t y = 0;
  uint32_t r, c;
  for (r = 0; r < 8; r++)
    for (c = 0; c < 8; c++)
      y |= ((x >> (r * 8u + c)) & 1u) << (c * 8u + r);
  return y;
}

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
