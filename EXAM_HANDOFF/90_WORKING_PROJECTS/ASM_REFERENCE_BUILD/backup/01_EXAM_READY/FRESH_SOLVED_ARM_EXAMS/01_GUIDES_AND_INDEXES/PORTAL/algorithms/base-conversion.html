Unsigned base conversion

Convert an unsigned word to base 2..16, uppercase digits, and append a terminator. Return digit count, or 0 before output writes on invalid base, null output or insufficient capacity.

Problem and contract

Convert an unsigned word to base 2..16, uppercase digits, and append a terminator. Return digit count, or 0 before output writes on invalid base, null output or insufficient capacity.

C interface

CODE
size_t u32_to_base(unsigned value, unsigned base, char *out, size_t cap)

Register map

FunctionArgumentEntry location
u32_to_baseunsigned valueR0
u32_to_baseunsigned baseR1
u32_to_basechar *outR2
u32_to_basesize_t capR3

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Collect remainders in a 32-byte scratch buffer.
  2. Check space for digits and terminator.
  3. Reverse the digits into output.

Worked trace

31,base16 -> "1F"; 5,base2 -> "101".

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
size_t u32_to_base(unsigned v, unsigned b, char *out, size_t cap) {
  if (!out || b < 2 || b > 16)
    return 0;
  char d[32];
  size_t n = 0;
  do {
    unsigned x = v % b;
    d[n++] = (char)(x < 10 ? 48 + x : 55 + x);
    v /= b;
  } while (v);
  if (cap <= n)
    return 0;
  for (size_t i = 0; i < n; i++)
    out[i] = d[n - 1 - i];
  out[n] = 0;
  return n;
}

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
