Safe starting sequence

  1. Copy the supplied starting template for the chosen exam.
  2. Keep the existing project files and startup code in place.
  3. Edit only the answer surfaces requested by the question.
  4. Build once before adding logic so setup failures are separated from answer failures.
  5. Add one feature at a time and rebuild.

Use relative package paths. Do not rename startup, project, or board-support files unless the exam explicitly requires it.

Current answer files

Edit Source/sample.c and Source/ASM_funct.s in your copied sample.uvprojx. Existing IRQ files retain one owner per vector. Historical answer-file names describe historical sources only.

Canonical template

Use the Official Combined Exam API · Read the solved-answer integration guide

Copy the complete maintained answer into Source/sample.c so its handlers, static state, and helpers stay together. Remove only conflicting handler definitions from the existing template IRQ sources, following the integration guide. The API contract is Source/exam_api/exam_api.h.
