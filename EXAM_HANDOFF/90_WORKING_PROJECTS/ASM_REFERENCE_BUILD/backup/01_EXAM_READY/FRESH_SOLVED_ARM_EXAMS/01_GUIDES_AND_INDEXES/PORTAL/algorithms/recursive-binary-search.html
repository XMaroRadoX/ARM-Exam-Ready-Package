Recursive binary search

Problem and contract

Search ascending signed words, n<=INT32_MAX. Return a matching index or -1; any occurrence is allowed for duplicates. Empty or null input returns -1. At most 32 recursive frames.

C interface

CODE
int32_t recursive_binary_search(const int32_t *a, uint32_t n, int32_t key)

Register map

FunctionArgumentEntry location

Stack locations above are measured at function entry. Add the bytes pushed or reserved by the prologue before loading a later argument. A word result returns in R0; a 64-bit integer returns low word in R0 and high word in R1. Modified R4–R11 registers must be restored, and SP must retain eight-byte alignment at a call.

How to solve it

  1. Choose the middle element.
  2. Recurse on the half that can contain the key.
  3. Offset a successful right-half result back into the original array.

Worked trace

[1,3,5,7,9], key 7: middle 5 -> right half [7,9] -> 7, original index 3.

Matching C

Show readable C reference
Open raw C file
C
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
int32_t recursive_binary_search(const int32_t *a, uint32_t n, int32_t key) {
  if (!a || !n || n > INT32_MAX)
    return -1;
  uint32_t m = n / 2;
  if (a[m] == key)
    return (int32_t)m;
  if (key < a[m])
    return recursive_binary_search(a, m, key);
  int32_t p = recursive_binary_search(a + m + 1, n - m - 1, key);
  return p < 0 ? -1 : (int32_t)(m + 1) + (int32_t)p;
}

int32_t recursive_binary_search(const int32_t *a, uint32_t n, int32_t key);
int test_main(void) {
  int32_t a[] = {1, 3, 5, 7, 9}, b[] = {INT32_MIN, 0, INT32_MAX};
  CHECK(recursive_binary_search(a, 5, 7) == 3);
  CHECK(recursive_binary_search(a, 5, 8) == -1);
  CHECK(recursive_binary_search(b, 3, INT32_MIN) == 0);
  CHECK(recursive_binary_search(b, 3, INT32_MAX) == 2);
  CHECK(recursive_binary_search(0, 0, 3) == -1);
  return 0;
}

Adapting it in an exam

  • Keep the declared element width and signed comparisons together when changing the input type.
  • Distinguish a returned value, an index, a count and a status flag before changing the calling C code.
  • Check the stated storage, overlap, arithmetic and recursion limits before using a larger example.
  • For a nested BL call, preserve live arguments and the return address as shown in the implementation.
