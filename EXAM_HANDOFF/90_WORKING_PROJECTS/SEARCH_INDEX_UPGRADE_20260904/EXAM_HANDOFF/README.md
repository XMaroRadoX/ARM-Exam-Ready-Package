# ARM Exam Handoff

Open [START_HERE.html](START_HERE.html). It is the only navigation page you need
to remember.

Double-click `START_HERE.html` to use the package locally. No web server,
installation, or internet connection is required. Keep this folder together.

- `01_EXAM_READY` contains the canonical exam workstation and the restored
  `Official Combined Exam API` starting project.
- `02_ORIGINAL_MATERIALS` contains the original exams, exam rules, ARM lectures,
  Keil material, and architecture lectures.
- `03_ADDITIONAL_STUDY_MATERIAL` contains source lessons and code used by the
  canonical workstation.
- `90_WORKING_PROJECTS` is the only place for personal practice and exam copies.

Do not edit the canonical project under `01_EXAM_READY/02_STARTING_TEMPLATES`
directly. Copy `Official Combined Exam API` into `90_WORKING_PROJECTS`, rename
the copy, and solve the question there. Open `sample.uvprojx`; the authoritative
API contract is `Source/exam_api/exam_api.h`.
