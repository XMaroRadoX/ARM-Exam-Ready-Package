Required include and initialization

C
#include "exam_api.h"

int main(void) {
  exam_init();
  /* Initialize only the peripherals required by the question. */
  for (;;) { __WFI(); }
}

exam_init() initializes system and LED support and clears API software state. It does not initialize or start every peripheral.

Ownership and data flow

  1. Use one owner for each peripheral and each IRQ vector.
  2. Initialize shared state, clear pending hardware state, enable interrupts, and start the time source last.
  3. In the IRQ, acknowledge the real source and capture a small value or publish an event.
  4. In main(), atomically take that state and perform longer processing.
Timer / RITConfiguration leaves the counter stopped; start explicitly.
SysTickSuccessful configuration starts it immediately.
ADCStart → IRQ capture → foreground take.
ButtonsChoose raw acknowledgement or one debounce workflow.

Exam-grounded values and scenarios

Every function page now separates evidence from teaching defaults. A number observed in one question is not automatically correct for another clock, timer mode, or requirement.

Observed in reviewed solutionsLinked to the maintained solved exam where the value or pattern appears.
Recommended maintained recipeA practical package default, such as 10 ms sampling and 50 ms button confirmation, not a claimed paper constant.
Safe illustration or API contractValid current-template usage with no claim that a reviewed exam used that exact value.

Choose the correct interface

SituationUse
The Combined API is permittedUse the declarations documented here exactly.
The paper supplies a named functionUse the professor's exact interface.
The paper tests registers or handler ownershipUse the required native/register implementation.

Never configure the same timer, interrupt, or peripheral through two interfaces.

Capabilities not present in the current API

These older conveniences are intentionally reported as gaps, not restored or presented as current declarations.

  • Core conveniences absent: exam_idle, exam_self_test. Use __WFI directly when sleeping is appropriate; the template does not claim a board self-test API.
  • Retired LED names absent: exam_led_from_board_label, exam_led_set, exam_leds_bar, exam_leds_clear, exam_leds_fill, exam_leds_read, exam_leds_write.
  • Retired button names absent: exam_button_irq_start, exam_button_is_down, exam_button_pressed_edges, exam_button_released_edges, exam_buttons_confirmation_ms, exam_buttons_down, exam_buttons_start.
  • Retired joystick names absent: exam_joystick_down, exam_joystick_first, exam_joystick_released_edges, exam_joystick_reset_first, exam_joystick_start. The current API stores no key-repeat policy.
  • Retired ADC and potentiometer names absent: exam_adc_read_raw, exam_potentiometer_read_percent, exam_potentiometer_read_raw, exam_potentiometer_start.
  • Retired DAC names absent: exam_dac_play, exam_dac_silence, exam_dac_stop, exam_dac_write_percent, exam_dac_write_raw. Playback scheduling belongs to question code.
  • Retired RIT and SysTick names absent: exam_rit_ticks, exam_systick_periodic_ms, exam_systick_ticks.
  • Retired general-timer names absent: exam_timer_capture_happened, exam_timer_clock_divider, exam_timer_free_running_start, exam_timer_match, exam_timer_match_happened, exam_timer_periodic_hz, exam_timer_periodic_ms, exam_timer_prescaler.
  • The current API has no callback-registration layer. Put question-specific work in the existing IRQ source or publish an event to main.
  • EXAM_TIMER_FREE_RUNNING is only a compatibility alias for EXAM_TIMER_MODULO_NO_IRQ, not a true unrestricted 32-bit free-running mode.

Function groups

Core

Initialize the board support and reset the API's shared software state.

FunctionPurpose
exam_initInitialize the LPC1768 system clock and LED support, then clear every software flag and cached API state.

LEDs

Control the eight board LEDs through the professor-compatible LED driver.

FunctionPurpose
exam_led_onTurn on one LED using its printed board label, 4 through 11.
exam_led_offTurn off one board LED while preserving every other LED.
exam_led_toggleInvert one LED based on the driver shadow state.
exam_led_one_hotShow exactly one lit LED selected by its printed board label.
exam_led_writeWrite the complete eight-bit LED pattern.
exam_led_readRead the API's current eight-bit LED shadow value.
exam_led_clearTurn off all eight LEDs.

Buttons

Use raw external interrupts or the API's time-source-independent debounce state machine.

FunctionPurpose
exam_buttons_initConfigure INT0, KEY1, and KEY2 as falling-edge external interrupts and reset button/debounce state.
exam_button_ackAcknowledge one LPC1768 external-interrupt button source.
exam_button_is_pressedRead the current active-low GPIO level of one board button.
exam_debounce_configSet the number of periodic samples required to confirm a button press.
exam_debounce_beginBegin debouncing a button after its external interrupt fires.
exam_debounce_tickAdvance every active button debounce state by one configured sample interval.
exam_button_events_takeAtomically obtain and clear all confirmed debounced button events.

Timers

Configure and control Timer0 through Timer3 using MR0 and the selected timer's real peripheral clock.

FunctionPurpose
exam_timer_config_ticksConfigure Timer0..Timer3 MR0 from an exact peripheral-clock tick count.
exam_timer_config_msConfigure Timer0..Timer3 MR0 from a millisecond period using that timer's actual PCLK.
exam_timer_config_hzConfigure a Timer0..Timer3 periodic interval from a requested frequency.
exam_timer_startStart a previously configured hardware timer.
exam_timer_stopStop one hardware timer without clearing its counter.
exam_timer_resetReset a timer counter to zero and leave it stopped.
exam_timer_readRead the current TC count from one hardware timer.
exam_timer_ackSnapshot and clear all active Timer match/capture interrupt flags.
exam_timer_is_runningTest the enable bit of one hardware timer.

SysTick

Start or stop the Cortex-M3 system tick for short periodic work.

FunctionPurpose
exam_systick_config_ticksConfigure and immediately start SysTick with an exact core-clock tick period.
exam_systick_config_msConfigure and immediately start SysTick from a millisecond period.
exam_systick_stopDisable SysTick counting and its interrupt.

RIT

Configure and control the LPC1768 Repetitive Interrupt Timer.

FunctionPurpose
exam_rit_config_ticksConfigure RIT with an exact tick count and leave it stopped.
exam_rit_config_msConfigure RIT from a millisecond interval and leave it stopped.
exam_rit_startEnable a previously configured RIT.
exam_rit_stopDisable RIT without changing its documented configuration.
exam_rit_resetReset the RIT counter through the professor driver.
exam_rit_ackAcknowledge the active RIT interrupt.

Joystick

Read the five active-low joystick controls and derive new press edges.

FunctionPurpose
exam_joystick_initConfigure P1.25..P1.29 as unmasked GPIO inputs for the five-way joystick.
exam_joystick_readReturn the current pressed-state mask for all five active-low joystick controls.
exam_joystick_pressed_edgesDerive controls that changed from released to pressed between two joystick samples.

ADC

Start one channel-5 conversion, capture it in the IRQ, and consume the fresh 12-bit result in main.

FunctionPurpose
exam_adc_initInitialize ADC channel 5 on P1.31 and clear the API's cached result state.
exam_adc_startStart one ADC conversion using the configured channel-5 driver.
exam_adc_irq_captureCapture a completed 12-bit ADC result into the API's interrupt-to-main mailbox.
exam_adc_takeAtomically take the newest captured ADC sample if one is fresh.
exam_adc_show_high8Display ADC result bits 11:4 on the eight LEDs.

DAC

Initialize P0.26 as AOUT and write a validated 10-bit sample.

FunctionPurpose
exam_dac_initConfigure P0.26 as DAC AOUT with deterministic zero output and fast-mode BIAS=0.
exam_dac_writeWrite one validated 10-bit DAC sample while preserving DACR.BIAS.

Events

Transfer bit flags safely between interrupt handlers and foreground code, or protect a short compound update.

FunctionPurpose
exam_events_setAtomically OR application-defined bits into the general interrupt-to-main event word.
exam_events_takeAtomically obtain and clear selected application event bits.
exam_critical_enterSave PRIMASK, disable maskable interrupts, and issue a data-memory barrier.
exam_critical_exitRestore the exact PRIMASK state saved by exam_critical_enter().

Faults

Configure Cortex-M3 fault trapping and preserve a debugger-readable exception snapshot when fault wrappers are enabled.

FunctionPurpose
exam_faults_configureEnable or disable configurable Cortex-M3 faults and the divide-by-zero and unaligned-access traps.
exam_fault_snapshot_clearMark the debugger fault snapshot as invalid before a new test.
exam_fault_capture_from_exceptionCopy the stacked exception frame and Cortex-M3 fault registers into persistent debugger state, then stop forever.

SVC

Decode an SVC immediate and pass the stacked exception frame to an overridable dispatcher.

FunctionPurpose
exam_svc_capture_from_exceptionDecode the SVC immediate from the instruction before stacked PC and dispatch the service with the stacked frame.
exam_svc_dispatchProvide the weak overridable hook that implements question-specific SVC services.
