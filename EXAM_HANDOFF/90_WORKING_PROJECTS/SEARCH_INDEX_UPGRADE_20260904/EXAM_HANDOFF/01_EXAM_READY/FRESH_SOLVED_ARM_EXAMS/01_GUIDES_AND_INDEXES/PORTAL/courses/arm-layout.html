Understand the idea

A matrix is a storage layout plus a coordinate rule. For a flat rows-by-cols matrix, element index=r*cols+c. Multiply by element size only once. Test rectangular examples because square ones can hide a wrong stride.

Structures use field offsets determined by the compiler's target ABI, including padding. Shared layouts need verified offsets and widths. A packed bit matrix has eight logical elements per byte and cannot use ordinary word addressing for each cell.

To access bit k, separate container index k/word_bits and bit position k%word_bits. Masking and shifting recover the logical value. State row order and bit order in the contract before translating a packed representation.

Worked example

Illustrative fragment unless explicitly marked as a complete project below. Read the contract and required placement before copying.

ASSEMBLY
; R0 = base, R1 = row, R2 = column, R3 = columns
        MUL R1, R3, R1
        ADD R1, R1, R2
        LDR R0, [R0, R1, LSL #2]
        BX LR

Execution trace

2-by-3 word matrix, row=1,col=2: index=5 → offset=20 → read the sixth element.

Try it before the answer

Locate logical bit 13 in a flat byte-packed array with least-significant-bit-first order.

Hint 1

Each byte contains eight logical bits.

Hint 2

Remainder selects the position inside the byte.

Reveal the worked answer

Byte index=13/8=1; bit position=13%8=5. Read byte 1, shift right by 5, AND with 1. This mapping changes if the contract uses another bit order.

Common mistakes and symptoms

Assuming tightly packed structures yields wrong offsets. Mixing element count and byte count oversteps buffers.

Checkpoint

Derive an address from dimensions, element size, and packing convention.

Row-major matrix

For matrix[row][column] with columns columns and element size size:

Show TEXT code
TEXT
byte address = base + ((row * columns) + column) * size

Preserve the outer row state while the inner loop changes column scratch registers. Check both dimensions before any load.

Structure

Assembly receives a pointer, not a copy of the structure. Use verified field offsets and matching signed loads. C padding can move later fields; verify with sizeof and offsetof instead of guessing.

Packed bits

Write down bit order before coding: most-significant-bit first or least-significant-bit first. Use masks and shifts to extract one bit, and clear the destination field before inserting a replacement.
