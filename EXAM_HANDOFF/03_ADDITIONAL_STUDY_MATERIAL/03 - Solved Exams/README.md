# Solved exams

Use the [past-exam search index](PAST_EXAM_SEARCH_INDEX.md) to search all 48
questions by algorithm, peripheral, event, timing mode, data layout, AAPCS
contract, failure risk, or alternate wording. Use the chronological index only
when you already know the date.

This directory contains one compact answer package for each of the 23 indexed
exams. Open [full solution status](FULL_SOLUTION_STATUS.md) for the coverage
summary before choosing an example.

Each dated directory contains:

- `EXAM_MAPPING.md`: source question and requirement mapping.
- `ADAPTATION_MAP.md`: values or policies most likely to change.
- `CHANGE_BUDGET.md`: expected edit size for common variants.
- `Answer Source/assembly.s`: assembly answer.
- `Answer Source/main.c`: board/application answer.
- `Answer Source/main.c declarations`: answer interface.
- `Answer Source/main.c`: complete program entry point.

The fastest lookup is normally through the
[exam chronology](../04%20-%20Reference/Atlas%20Data%20and%20Indexes/ARM_EXAM_ATLAS/exams/INDEX.md),
which links each paper to its corresponding solution and pattern family.
